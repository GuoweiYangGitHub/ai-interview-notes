# 中国移动集团网络拓扑

> 集团级网络资源管理和运行监控的三维可视化平台：地球总览 → 区域 3D 拓扑 → 2D 逻辑拓扑，支持多层级聚合与下钻。

## 用 3 分钟介绍这个项目

中国移动集团网络拓扑是集团级网络资源管理和运行监控的三维可视化平台，用地球场景展示集团、省份和区域的网络资源，支持 **3D 拓扑**和 **2D 逻辑拓扑**多层级查看。

我参与三维拓扑模块的设计和开发：地球与 3D 拓扑联动、3D / 2D 构建与切换、设备 / 线路 / 标签 / 告警管理，以及专线等业务数据适配。

布局按节点数、连接数、双向 / 备用线路比例和中心节点判断**树状、链式、星型 / 复杂拓扑**，用**邻接表**算层级和坐标；同一对设备多条线做**平行偏移**。交互支持线路高亮、双击下钻、按业务筛线、相机飞行、视角保存 / 恢复和标签显隐。

我独立完成的**聚合下钻**功能已经迁入中国移动项目。

## 1. 项目场景

面向集团、省份和区域的网络资源管理与运行监控。用地球场景展示资源分布，支持 3D 拓扑和 2D 逻辑拓扑两种视图，既能看空间层级，也能看逻辑连接。业务数据包括专线、党政军、互联网专线等。

## 3. 拓扑怎么画

### 3.1 先判断拓扑类型

不是所有网络都画成同一种形状。布局前先看：

- 节点数和连接数；
- 双向 / 备用线路比例；
- 是否存在中心节点；
- 是否多根、并行、环形。

据此选择树状、链式、星型或复杂拓扑。标准结构用规则布局，复杂结构再走力导向或分层布局。

### 3.2 用邻接表算层级和坐标

- 邻接表保存节点与线路关系，便于算层级、找中心节点和遍历。
- 按层级分配坐标，再在层内做横向展开。
- 同一对设备之间有多条线时，做平行偏移，避免完全重叠。
- 布局结果保留节点原始业务 ID，切换 2D / 3D 时复用同一份拓扑数据。

### 3.3 3D 与 2D 分工

- **3D**：看空间层级、地球到区域的总览、设备与线路的立体关系。
- **2D**：看逻辑连接、业务筛选和细节排查。
- 两种视图共享拓扑数据；切换时保留当前选中、业务过滤和层级上下文。

## 4. 交互与相机

- 线路单击高亮，双击下钻到下一层；空白处取消选中。
- 按业务类型筛线，选中设备时关联线路高亮。
- 相机飞行到目标区域；支持视角保存 / 恢复。
- 根据距离调整标签显隐和大小，避免近处拥挤、远处看不清。
- 从 3D 线路双击进入 2D 逻辑拓扑，再返回原来的 3D 视角。

## 5. 聚合与下钻

- 按集团 → 省份 → 区域维护聚合层级。
- 上层节点保留子节点数量、告警汇总和业务类型分布。
- 下钻时按当前 scope 重新取子图，而不是一次加载全量。
- 返回时恢复父级视角、选中状态和过滤条件，避免“下钻后找不到刚才的位置”。
- 聚合下钻功能已迁入中国移动项目。

## 8. 高频追问

### 为什么同时要 3D 和 2D 两套拓扑？ {#q01}

3D 适合看空间层级和地球到区域的总览，2D 适合看逻辑连接和细节排查。两套视图共享同一份拓扑数据，切换时保留选中、过滤和层级上下文。只用 3D 会在细节排查时遮挡严重；只用 2D 又失去空间层级。

### 复杂拓扑怎么自动布局？ {#q02}

先按节点数、连接数、双向/备用线路比例和中心节点判断类型。标准结构用树状、链式、星型规则布局；复杂结构用分层或力导向布局，再用邻接表算层级、做碰撞检测和线路偏移。布局不是一次到位，要允许人工微调和视角恢复。

### 同一对设备多条线怎么处理？ {#q03}

不能完全重叠。按线路数量做平行偏移，偏移方向与主线路垂直；偏移量随缩放级别调整，避免近处分开、远处又糊在一起。选中某条线时高亮并显示业务信息。

### 聚合下钻怎么保证不丢上下文？ {#q04}

上层节点保留子节点计数和告警汇总；下钻按 scope 取子图；返回时恢复父级视角、选中和过滤条件。聚合数据和明细数据分开缓存，避免每次下钻都全量重建。

### 相机和标签怎么不打架？ {#q05}

相机按目标区域飞行，距离变化时调整标签显隐和大小；标签做避让和层级筛选，近处显示更多，远处只保留关键节点。视角保存 / 恢复要同时记录相机位置、目标点和缩放级别。

### 和江中智能助手的场景定位有什么区别？ {#q06}

中国移动项目是网络资源拓扑，重点是 3D/2D 拓扑布局、线路关系和聚合下钻；江中助手是对话式业务助手，场景定位只是它的一环，重点是 `classify → route → act`、工具调用、审批和场景回执。两者都用 ThingJS，但一个以三维拓扑为主体，一个以对话和业务办理为主体。
