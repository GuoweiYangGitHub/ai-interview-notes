# 项目实战

两个 AI 项目 + 一个三维前端项目。这里只保留**面试问答、关键取舍、数字口径和讲法**；源码与架构长文已归档，不在手机复习时读源码。

## THINGJS 文档 RAG

面向 ThingJS 官方文档的 RAG 问答系统。重点：结构化切片、向量 + BM25 混合检索、RRF、父块补全、证据守卫、黄金集与发布门禁。

适合讲：RAG 全链路、检索评估、索引热更新、前端 SSE 与引用展示。

## 江中智能助手

面向制药数字孪生场景的对话式业务助手。重点：`classify → route → act` 分层编排、LangGraph 子图、只读计划执行器、场景宿主回执、审批与评测闭环。

适合讲：Agent 边界、工具调用、LangGraph 状态与恢复、宿主前端模块、质量闭环。

## 中国移动集团网络拓扑

集团级网络资源管理和运行监控的三维可视化平台。重点：地球与 3D 拓扑联动、3D/2D 拓扑构建与切换、树状/链式/星型/复杂拓扑布局、线路平行偏移、相机飞行与视角恢复、多层级聚合下钻。

适合讲：三维前端、拓扑布局、相机与标签、聚合下钻。
