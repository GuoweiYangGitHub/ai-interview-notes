# THINGJS 文档 RAG · 3 分钟演讲稿

ThingJS 文档问答系统面向官方文档和示例代码，网页助手和编辑器通过工具协议共用一套检索、生成链路。

文档按 Markdown 结构和代码语法树切分，保留类 / 成员身份和父块；检索走**向量 + 关键词检索**，用**排名融合**把两路结果合并，再做**精确符号置顶**、类 / 成员采纳和**父块回填**；生成用 YAML 提示词 + LangChain 表达式，做证据筛选、领域守卫和引用校验。

索引按文件内容指纹增量构建，索引清单校验后切激活指针；文档改动可热更新，发布门禁失败回滚。评测有 100 题检索集、30 题生成集和 12 题自动评审校准，另加覆盖集、真实问法和代码题；三套门禁绑定配置版本。

我负责前端、检索、生成和评测。三句话：**切片不是固定长度**；**混合检索同时解决语义和精确符号**；**引用检查只能保证引用真实存在，不能保证引用支持结论**。
