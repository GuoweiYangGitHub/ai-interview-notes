看图时按 1–6 讲：

1. **系统整体流程**：前端 → API → 检索 → 生成 → 评测 / 发布。
2. **离线索引流程**：文档新增 / 修改 / 删除 → 解析 → 切片 → 向量化 / 关键词检索 → 索引版本。
3. **在线检索问答**：意图 / 查询计划 → 双路召回 → 排名融合 → 父块 → 生成 → 证据守卫。
4. **评测系统**：检索 / 生成评测、自动评审、回归。
5. **检索黄金集**：固定题集与基线。
6. **发布门禁系统**：索引清单 / 激活指针、门禁、回滚。

另外三块：记忆系统、会话管理、日报和混合排序。
