# 江中智能助手 · 3 分钟演讲稿

江中智能助手是面向制药车间内网的对话式业务助手。用户可以用自然语言查规程、设备状态、告警、工单、库存和批次，也可以办理批次追溯、维修工单、巡检，并定位到三维场景里的设备。

我独立交付了 Vue 3 对话前端和 TypeScript / Express 服务端。服务端不是一个大提示词，而是**分类 → 规划 → 执行**：先判断意图，再产出目标和结构化计划，最后由**计划编译器**校验工具、参数、依赖和写边界，交给**计划步骤 / 计划汇总**执行；固定业务流程编译成 LangGraph 子图。

写操作必须走**提议 → 审批 → 执行**，确认幂等并写审计；三维动作交给宿主执行，**没有回执不算成功**。会话、图状态、审批和场景回执存 PostgreSQL，服务重启后能续接，**状态不明不自动重放**。

评测分两层：第一层用**固定断言**检查工具、流程和状态等确定性行为；第二层按**任务完成、安全拦截、数值溯源**做质量门禁。用例覆盖正常问答、多步任务、缺参、越权、空结果、工具失败和注入；不达线就阻断发布。审阅台支持回放、人工标注、参考标准对比和回归用例。

三句话收尾：**模型负责理解和提议，程序负责边界和结算**；**没有回执不算成功**；**评测和门禁让改动可回归**。
