# 江中智能助手 · 3 分钟演讲稿

江中智能助手是江中集团制药车间的对话式业务助手。用户可以用自然语言查知识库、查中台数据，能办批次追溯、工单，也可以定位三维场景。

我负责的是助手前端展示页、3D 场景对接流程、后端服务和评测页面。

前端展示页是嵌入在宿主里的对话窗口，回答流式输出，审批和场景用卡片展示，用户能看到执行状态和回执。

服务端拆成几个模块，用户问题进入之后先走**分类 → 规划 → 执行**：先判断意图，再产出计划，由计划编译器校验工具、参数和写边界；固定流程例如批次追溯、工单，会被编译成 LangGraph 子图。

评测分两层。第一层用模拟数据跑固定检查，看工具选择、参数格式、步骤顺序这些对不对；这些都是写死的，不靠模型判断。第二层接真实模型，看任务有没有完成、安全问题有没有拦住、回答里的数字能不能在工具结果里找到。工具成功不等于交付完成，缺项要说清楚。能确定的错，比如参数错、越权、没回执，程序先判；裁判只看回答有没有覆盖问题、依据够不够，不能把程序判定的错改成通过。用例覆盖缺参、越权、工具失败和注入，不达线就阻断发布。

**模型负责理解和提议，程序负责边界和结算**；**没有回执不算成功**；**评测和门禁让改动可回归**。
