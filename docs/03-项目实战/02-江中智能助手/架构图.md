看图时按三条线讲：

- **系统架构**：宿主聊天窗口 → 后端服务器 → 助手节点 → 模型服务 / 工具与场景节点 / 业务中台 / Dify 知识库。
- **智能体运行流程**：分类 → 规划 → 计划编译 → 执行；只读走计划步骤 / 计划汇总，固定业务走子图，写操作进审批，三维动作交宿主并等回执。
- **LangGraph 主图**：每轮从 `START` 进入固定流程子图或 `assistant`，再按 `executionPhase` 进入 `plan_join` / `executor`，最后按 `tool_calls` 进入 `tools`。
