### 了解 async/await

`async` 会把函数的返回值用 `Promise.resolve()` 包裹一下，和 `await` 配套使用，本质是 Promise 和 Generator 的语法糖。

### promise 三个状态

`pending`、`resolved`（完成）、`rejected`（失败）。

```js
var promise = new Promise((resolve, reject) => {
  if (/* 操作成功 */ true) {
    resolve(value);
  } else {
    reject(error);
  }
});

promise
  .then((value) => {
    // success
  })
  .catch((error) => {});
```

Promise 有两个特点：对象的状态不受外界影响；一旦状态改变，就不会再变。

### promise.all 与 promise.race 的区别

`promise.all([a, b, c])` 中，如果一个失败，都不会走 then 方法。

### 手机端使用 echarts 有没有遇到过什么问题

- 优化：可以把 DOM 和 echartsDOM 保存在 data 中，这样不必每次都初始化一遍。
- 高度为 0 的问题：动态设置宽高。
- `echartsDOM.clear()`：多个功能共用一个 echartsDOM 时，切换的时候横纵坐标会重叠，通过 `clear()` 移除实例中所有的组件和图表。
- 移动端 echarts 字号的设置不受浏览器最小字号限制，可以随意设置更符合界面显示需要的字号。
- tooltip 显示框优化：
  - tooltip 默认出现在用户交互的数据点附近，PC 端没有问题；移动端是手指触摸产生的，在触摸点展示会导致 tooltip 显示不全。
  - 解决办法：动态设置 tooltip 位置；给 tooltip 固定位置，左侧或右侧；给 tooltip 设置 `confine: true`，防止图形溢出。
- 折线图最小值数值优化：动态设置最小值。

### 怎么封装一个 echarts 的公共组件

```js
// 1. 获取一个用于挂载 echarts 的 DOM 元素
let $echartsDOM = document.getElementById('echarts-dom');

// 2. 初始化
let myEcharts = echarts.init($echartsDOM);

// 3. 设置配置项
let option = {};

// 4. 为 echarts 指定配置
myEcharts.setOption(option);
```

```js
mounted() {
  let $echartsDOM = document.getElementById('echarts-dom');
  let myEcharts = echarts.init($echartsDOM);
  let option = {
    title: {
      text: 'ECharts 入门示例'
    },
    tooltip: {},
    legend: {
      data: ['销量']
    },
    xAxis: {
      data: ['衬衫', '羊毛衫', '雪纺衫', '裤子', '高跟鞋', '袜子']
    },
    yAxis: {},
    series: [{
      name: '销量',
      type: 'bar',
      data: [5, 20, 36, 10, 10, 20]
    }]
  };
  myEcharts.setOption(option);
}
```
