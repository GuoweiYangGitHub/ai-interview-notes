## 60 秒讲法

> 这是一个制药数字孪生场景的对话式业务助手。浏览器宿主内的可移植对话模块发消息，Express 网关用 LangGraph 编排「理解 → 规划 → 执行 → 审批 / 场景动作」；中台能力经 MCP 动态发现；三条固定流程用子图逐步推进，普通只读查询走有界依赖的计划执行器；三维动作由宿主注册并回执；会话、图状态、后台运行、长期记忆、审阅和人工标注都存 PostgreSQL。质量上不只做执行断言，还做逐题交付判定、人工标注、归因校准和回归草稿。

## 3 分钟讲法

按演示主线走，每段只留一个证据：

1. 开场 10 秒：一句话定位 + 左边聊天、右上有三维执行记录。
2. 复合查询：输入「查一下 SANC03 当前告警、未关闭工单、近七天重复告警」，指计划和证据（40 秒）。
3. 批次追溯：「批次追溯」→「B20260001」→「正向」（35 秒）。
4. 三维：「飞到 3 号设备」，指右上「三维生效」（25 秒）。
5. 工单：「维修工单」→「WO-DEMO-101」→「派工」→「technician」→ 说明 →「确认」（35 秒）。
6. 调试失败：`focus_device` + `{}`，指失败记录（20 秒）。
7. 审阅台：链路 → 交付表 → 标注（30 秒）。
8. 收尾：评测数字 + 边界（15 秒）。

收尾口径：

> 三条固定流程、15 个步骤节点、12 类只读计划动作、26 个场景方法；57 题 mock 全过、门禁通过；写操作全部人工确认，状态不明不重放；评测从执行断言延伸到交付、参考标准对比、人工标注和校准。边界是三维只验证了 3 个真实动作，第二层 live 还没在 57 题上重建基线，CI 门禁还没做。
