## 五条调用链

### 1. HTTP → 理解 → 计划 → 工具

```text
modules/chat/routes.ts
  → app/create-app.ts 鉴权/限流/幂等
  → agent/core/turn.ts
  → agent/core/graph.ts
  → agent/nodes/assistant.ts（classify → route → compilePlan）
  → agent/nodes/plan-executor.ts（plan_step / plan_join）
  → agent/planning/plan-compiler.ts（校验与派发）
  → agent/nodes/tools.ts / integrations/zhongtai/mcp.ts
```

### 2. 固定流程子图

```text
START → workflow_<kind>
  → agent/nodes/workflow.ts 入口
  → workflows/<kind>/index.ts run
  → 步骤节点
  → 回到主状态
```

### 3. 场景回执

```text
agent/nodes/tools.ts 识别场景动作
  → agent/nodes/scene.ts 写入 sceneActions
  → HTTP result
  → examples/host-demo/src/assistant/core/scene.ts 执行 handler
  → POST /scene/receipt
  → modules/scene/routes.ts
  → 宿主模块 continue 继续
```

### 4. 审批与写入

```text
提议工具 → tools 节点返回 approval
  → approval 节点结束本轮
  → POST /approval/decision
  → agent/nodes/approval.ts 执行写执行器
  → assistant_approval_audit
  → 结果不确定时要求人工核对
```

### 5. 评测与人工复核

```text
eval/run.ts → eval/runner.ts
  → 用例 + mock/live 模型
  → eval/assertions.ts + eval/delivery.ts + eval/judge.ts
  → eval/metrics.ts + eval/report.ts
  → eval/reports/<batch>/
  → review/eval/* 读取批次
  → review/annotations/* 人工标注、归因、校准、回归草稿
```

- 数字以当前代码、`logs/` 和 `eval/reports/` 为准；不要引用旧快照。
- 讲实现时优先给出真实文件路径，而不是只讲概念。

## 3 分钟极简版

1. 开场 10 秒。
2. 复合查询：「查一下 SANC03 当前告警、未关闭工单、近七天重复告警」，指计划和证据（40 秒）。
3. 批次追溯：「批次追溯」→「B20260001」→「正向」（35 秒）。
4. 三维：「飞到 3 号设备」，指右上「三维生效」（25 秒）。
5. 工单：「维修工单」→「WO-DEMO-101」→「派工」→「technician」→ 说明 →「确认」（35 秒）。
6. 调试失败：`focus_device` + `{}`，指失败记录（20 秒）。
7. 审阅台：链路 → 交付表 → 标注（30 秒）。
8. 收尾：评测数字 + 边界（15 秒）。

## 常见故障与兜底

| 现象 | 处理 |
| --- | --- |
| `pnpm start` 卡住 | 启动 Docker Desktop；或 `pnpm db:up` |
| 端口占用 | 关旧进程后重试 |
| 聊天 401 | 设置里换令牌；开发默认令牌只在本机 |
| 聊天 429 | 等 `Retry-After`，或调高 `RATE_LIMIT_PER_MINUTE` |
| 聊天 409 `session_busy` | 等上一轮结束或新建会话 |
| 场景未就绪 | 检查 ThingJS 登录、本地库、WebGL |
| 审批不出现 | 确认是写操作，且模型调用的是提议工具 |
| 审阅台 503 | `TRACE_ENABLED=true` 后重启 |
| 评测批次 404 | 批次号用报告目录名；检查 `eval/reports` |
| 裁判 403 | `JUDGE_MODEL` 未开通；临时换可用模型或关闭裁判 |
| 知识库无结果 | 检查 `DIFY_BASE_URL` 与 `DIFY_KB_*_KEY` |

## 一句话流程

> 打开宿主 → 问一句 → 看一次计划 → 走一条流程 → 看一次三维生效 → 点一次确认 → 看一次失败 → 查一条链路 → 看一次交付与标注 → 报一组评测数字。
