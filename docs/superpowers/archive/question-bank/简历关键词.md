# 简历关键词

> 简历上的每个关键词，面试官都可能顺着问。这里只给“他会怎么问 + 你怎么接 + 详细页”。

## Agent 运行时与业务编排

**面试官会问**：你用的 LangGraph 到底解决了什么？为什么不用一条链？工具怎么绑？写操作怎么保证不重复？

**一句话接**：固定流程写死顺序，江中的下一步取决于用户要做几件事和上一步查到了什么，所以用 `classify → route → act`；模型只提议，计划编译器校验，写操作走审批，状态和回执落 PostgreSQL。

**详细页**：[江中面试问答](/03-项目实战/02-江中智能助手/11-面试问答) · [关键取舍](/03-项目实战/02-江中智能助手/09-关键取舍)

## RAG 与检索质量

**面试官会问**：为什么不用固定长度切块？向量和 BM25 各解决什么？RRF 为什么比加权求和稳？引用能保证什么？

**一句话接**：按 Markdown 结构和代码 AST 切，保留类 / 成员和父块；向量补语义，BM25 补精确符号，RRF 按排名融合；引用检查只能保证引用真实存在，不能保证引用支持结论。

**详细页**：[THINGJS 项目问答](/03-项目实战/01-THINGJS文档RAG/12-项目问答) · [关键取舍](/03-项目实战/01-THINGJS文档RAG/09-关键取舍)

## 评测与门禁

**面试官会问**：你怎么证明改完没退化？裁判有偏差怎么办？门禁会不会误杀？

**一句话接**：L1 固定断言，L2 完成率 / 安全 / 溯源；裁判、人工标注、归因校准和回归草稿闭环；门禁绑定配置版本，不达线阻断发布。误杀时先看题集分母和阈值，再决定改系统还是改基线。

**详细页**：[江中面试问答](/03-项目实战/02-江中智能助手/11-面试问答) · [THINGJS 项目问答](/03-项目实战/01-THINGJS文档RAG/12-项目问答)

## AI 应用前端

**面试官会问**：SSE 怎么解析？取消和重试怎么做？审批卡怎么处理？引用和证据怎么展示？

**一句话接**：`ReadableStream + TextDecoder` 解析 SSE；`delta / reset / phase / done / error` 事件；增量预览不是最终答案，`done` 才是权威结果；`AbortController` 取消；审批卡只产出 patch，不自己提交；Markdown 渲染加 XSS 净化。

**详细页**：[THINGJS 项目问答](/03-项目实战/01-THINGJS文档RAG/12-项目问答) · [江中面试问答](/03-项目实战/02-江中智能助手/11-面试问答)

**面试官会问**：事件循环、原型链、闭包、Promise；Vue 响应式、组件通信、`v-model`；TypeScript 泛型和类型收窄。

**一句话接**：这些是十年基础，按“概念 → 例子 → 项目里怎么用”答。项目里最相关的是 SSE 状态机、审批卡、会话恢复和类型契约。

## 小程序 / 跨端

**面试官会问**：小程序生命周期、登录流程、扫码、定位、公共能力怎么抽？

**一句话接**：做过嘉士伯多品牌会员小程序，总用户 3000w+、日活 15w+；用 ES6 class 抽公共扫码逻辑和生命周期 hooks，定位和状态管理也复用；接口加密和表单校验防刷、防 XSS。

**详细页**：[小程序基础知识](/01-前端基础/08-小程序/基础知识) · [小程序面试题](/01-前端基础/08-小程序/面试题)

## 三维与大屏

**面试官会问**：3D / 2D 拓扑怎么分工？复杂拓扑怎么自动布局？聚合下钻怎么保留上下文？相机和标签怎么不打架？

**一句话接**：3D 看空间层级，2D 看逻辑连接，共享同一份拓扑数据；按节点数、连接数、双向 / 备用线路比例判断树状 / 链式 / 星型 / 复杂拓扑，用邻接表算层级和坐标；聚合按 scope 取子图，返回恢复父级视角和过滤条件。

**详细页**：[中国移动网络拓扑](/03-项目实战/04-中国移动网络拓扑) · [项目架构图](/04-面试题库/项目架构图)

## 工程化

**面试官会问**：Vite / Webpack 怎么选？pnpm workspace 怎么管？Playwright 测什么？Docker / CI / Nginx 做过什么？

**一句话接**：工程化不是工具清单，是交付效率和质量：构建、依赖、规范、测试、部署、回滚各有一件事能讲。项目里最相关的是 SSE 测试、索引发布门禁和配置版本。

**详细页**：[构建工具](/01-前端基础/06-工程化与性能/构建工具) · [自动化测试](/01-前端基础/06-工程化与性能/自动化测试)

## 两个 AI 项目怎么排序讲

先讲**江中 Agent**：它是主线，覆盖编排、工具、审批、状态、恢复和评测。  
再讲 **THINGJS RAG**：它证明检索、证据和评测深度。  
最后用**中国移动网络拓扑**补三维前端和复杂交互。不要三个项目平均用力。
