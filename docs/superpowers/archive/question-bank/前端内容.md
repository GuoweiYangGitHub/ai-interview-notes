## JavaScript

**高频题**

- 事件循环：宏任务 / 微任务，`Promise` 与 `async/await` 的执行顺序。
- 原型链：`prototype`、`__proto__`、`instanceof`、`new` 做了什么。
- 闭包：定义、用途、内存泄漏。
- 深浅拷贝：`JSON`、递归、`structuredClone` 的边界。
- 数组方法：`map / filter / reduce / flat / sort` 的返回值与副作用。
- 手写：`call / apply / bind`、防抖节流、`Promise`。

## TypeScript

**高频题**

- `type` 和 `interface` 的区别。
- 泛型：约束、默认值、泛型函数 / 接口 / 类。
- 条件类型与 `infer`。
- `keyof`、`typeof`、索引访问类型。
- 类型收窄：`typeof`、`in`、`instanceof`、判别联合。
- `unknown` vs `any`，`never` 的用法。

## CSS 与布局

**高频题**

- 盒模型、`box-sizing`。
- BFC：触发条件与用途。
- Flex / Grid 常见布局；两边固定中间自适应。
- 水平垂直居中；不定宽高居中。
- 移动端 1px、字体字重、兼容性。
- `display: none / visibility: hidden / opacity: 0` 的区别。
