# 考前清单

> 面试前 10 分钟扫一遍。完整题目在[面试题库](/04-面试题库/)左侧「P0 重点」，提问顺序见[面试官视角](/04-面试题库/面试官视角)。

## 开场

- [ ] 30 秒版：近 10 年前端 → 数字孪生 → AI 应用，主栈 TS/Node + Vue 3。
- [ ] 3 分钟版：前端底子、数字孪生、江中助手、ThingJS RAG、收尾。
- [ ] 能指着[项目架构图](/03-项目实战/架构图)说清两个项目的层次。

## 两个项目

### 江中智能助手

- [ ] 一句话：制药车间对话式业务助手，查数据、走流程、人工确认，三维动作交给宿主。
- [ ] 主链路：`classify → route → act`；只读计划最多 8 步、3 层依赖；固定流程编译子图。
- [ ] 写操作：提议 → 审批 → 执行；状态不明不自动重放。
- [ ] 前端：流式对话、审批卡、会话恢复、场景回执、`fetch` 注入。
- [ ] 评测：L1 固定断言 + L2 完成率 / 安全 / 溯源；审阅台回放与人工标注。
- [ ] 边界：`pnpm test` 有 1 个失败，不能说测试全绿；L2 live 尚未重建基线。

### ThingJS 文档 RAG

- [ ] 一句话：官方文档的检索问答，网页与编辑器 MCP 共用链路。
- [ ] 主链路：结构化切片 → 向量 + BM25 → RRF → 精确符号置顶 → 父块回填 → 证据守卫。
- [ ] 索引：文件 hash 增量、manifest 校验、active 指针切换、失败回滚。
- [ ] 前端：Vue 3 问答页、SSE 增量预览、引用/耗时/提示词检查器。
- [ ] 评测：100/30/12 题集；最近 23/24 被拦截，历史 24/24 通过。
- [ ] 边界：不建 ANN；限流在进程内；多实例需外置。

### 中国移动集团网络拓扑

- [ ] 一句话：集团级网络资源的三维可视化平台，地球总览 → 区域 3D 拓扑 → 2D 逻辑拓扑。
- [ ] 布局：按节点数、连接数、双向/备用线路比例和中心节点判断树状、链式、星型/复杂拓扑；邻接表算层级和坐标。
- [ ] 细节：同一对设备多条线做平行偏移；3D 看空间，2D 看逻辑，共享同一份拓扑数据。
- [ ] 交互：线路高亮、双击下钻、按业务筛线、相机飞行、视角保存/恢复、标签显隐。
- [ ] 聚合：集团 → 省 → 区域逐层下钻，返回恢复父级视角与过滤条件。
- [ ] 结果：独立完成的聚合下钻功能已迁入中国移动项目。
- [ ] 边界：没有更多线上量化指标；大规模性能优化只讲方案，不冒充已验证。

## 前端

- [ ] 事件循环、宏任务/微任务、Promise 与 `async/await`。
- [ ] 原型链、闭包、`this`、深浅拷贝。
- [ ] TypeScript 泛型、条件类型、类型收窄。
- [ ] Vue 响应式、组件通信、`v-model`；React Hooks、渲染优化。
- [ ] 浏览器缓存、HTTP、跨域、性能指标。
- [ ] SSE 流式、取消、背压、断线重连；Markdown 渲染与 XSS 净化。
- [ ] 工程化：Vite/Webpack、pnpm、ESLint、Husky、Playwright、Docker、Nginx。

## AI 应用

- [ ] RAG 全链路与失败定位：切片/召回/精排/组装/生成。
- [ ] 混合检索与 RRF；为什么不用单一向量。
- [ ] Agent 的适用边界；ReAct 与固定工作流的取舍。
- [ ] MCP 解决什么问题；工具参数为什么要运行时校验。
- [ ] LangGraph 的状态、节点、边、checkpoint、human-in-the-loop。
- [ ] 评测：黄金集、指标、LLM 裁判、回归与门禁。
- [ ] 成本与限流：token 预算、并发、缓存、超时与降级。

## 工程

- [ ] Node 单线程与异步；`Promise.all` 与并发限制。
- [ ] 超时、重试、幂等、降级与兜底。
- [ ] 可观测：trace、指标、日志、问题闭环。
- [ ] 发布：配置版本、门禁、回滚。

## 边界话术

- 微调 / 训练：`这块我没有生产级微调经验。我的判断是……如果要落地，我会先验证……`
- 分布式 / 多实例：`当前项目以单实例为主，扩展方案我会这样设计……但还没在生产验证。`
- Python / FastAPI：`主栈是 TypeScript / Node，Python 能读能改，不冒充主力语言。`
- 算法：`前端高频算法够用，更深的算法不是我的强项。`
