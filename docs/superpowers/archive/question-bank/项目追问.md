## 怎么用

1. 先按江中 P0 顺序练，每题录音 60–90 秒。
2. 再练 ThingJS P0，重点讲清“切片 → 检索 → 生成 → 评测”四层。
3. 中国移动只准备 60 秒和 3 个追问，不要抢 AI 主线的时间。
4. 每题都要能说出一句边界：哪些做了、哪些没做、哪些是模拟。
