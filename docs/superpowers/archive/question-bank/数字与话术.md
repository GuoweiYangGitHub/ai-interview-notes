# 数字与话术

> 报数字前先说口径：数据集多大、指标是什么、什么时候测的。详细出处见各项目的“数字速查”页。

## 1. 三个项目的 60 秒讲法

### THINGJS 文档 RAG

这是一个面向 ThingJS 官方文档的 RAG 问答系统。把 260 篇 Markdown 和 117 个示例代码文件切成 9,366 个语义块，用 Qwen3-Embedding-4B 做向量索引、MiniSearch + jieba 做 BM25，检索侧做“意图识别 → 查询计划 → 双路召回 → RRF → 精确符号置顶 → 父块补全”，生成侧用 LangChain LCEL + 结构化输出 + 证据守卫，最后通过 Web、MCP 和评测平台三个入口交付。

我重点做的是检索、生成和评测链路：让答案有引用、可回归，索引能增量更新并在失败时回滚。

### 江中智能助手

这是一个面向制药数字孪生场景的对话式业务助手。浏览器宿主里的对话模块把问题发给 Express 网关，网关先做 `classify → route → act` 分层理解，再由 LangGraph 主图编排“模型 → 工具 / 只读计划 → 审批 / 场景动作”。三条固定业务流程编译成子图，普通只读查询走最多 8 步的计划执行器，写操作必须人工确认。

我负责对话模块、场景宿主、网关和编排试点：重点是把模型的理解能力和程序的边界、结算分开。

### 中国移动集团网络拓扑

这是一个集团级网络资源管理和运行监控的三维可视化平台。用地球场景展示集团、省份和区域的网络资源，支持 3D 拓扑和 2D 逻辑拓扑多层级查看。我参与三维拓扑模块的设计和开发，做地球与 3D 拓扑联动、3D/2D 构建与切换、设备/线路/标签/告警管理，以及专线等业务数据适配。拓扑布局会按节点数、连接数、双向/备用线路比例和中心节点判断树状、链式、星型或复杂拓扑，用邻接表算层级和坐标；同一对设备多条线做平行偏移。交互上支持线路高亮、双击下钻、按业务筛线、相机飞行和视角保存/恢复。独立完成的聚合下钻功能已经迁入中国移动项目。

这个项目没有可公开的量化指标，讲结构、布局和交互，不编数字。

## 4. 讲数字的三个规矩

1. **带分母**：说“24 题可回答生成集上裁判幻觉 0”，不说“幻觉 0”。
2. **带时间**：说“2026-11-22 mock 评测 57/57”，不说“全部通过”。
3. **带边界**：测试有失败就说有失败；mock 延迟不代表真实模型延迟。
