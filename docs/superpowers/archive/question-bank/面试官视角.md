# 面试官视角：如果我来面你

> 你的简历主线是 **Agent 运行时 + 业务编排 + 前端交付**，不是“通用 AI 八股”。所以我会把大部分时间放在江中 Agent 项目，其次用 ThingJS RAG 验证检索与评测深度，最后用前端和工程题确认你能不能落地。China Mobile 用来验证三维前端和复杂交互，不作为 AI 主线。

## 1. 先给判断

- **最强信号**：独立交付服务端 + Vue 3 对话前端 + LangGraph 编排 + 写操作审批 + 场景回执。这不是“调 API”，是把模型接进业务。
- **最容易被追问**：哪些是你写的？Agent 和固定工作流的边界在哪？写操作怎么保证不重复？评测是不是自己出题自己判？
- **最容易被问倒**：微调/训练、分布式多实例、Python 主力开发。这些要提前准备边界话术。
- **不建议平均用力**：不要花大量时间背通用八股。先把 P0 十二问答到能录音 90 秒，再补 RAG 和前端细节。

## 4. P0 十二问

### [重点] 1. 用一分钟介绍江中，你负责哪几块？为什么这个项目需要 Agent，而不是固定流程？

**面试官想验证**：你是否真的拥有项目，能不能把业务问题翻译成技术方案。

**你的答题锚点**：

- 独立交付 Vue 3 对话前端 + TypeScript/Express 服务端。
- `classify → route → act`；只读查询走计划执行器，三条固定业务编译成子图。
- 不是所有请求都进 Agent：固定流程用子图，普通只读用计划，写操作必须审批。

**追问链**：哪些代码不是你写的？为什么不用一个大 Prompt？如果所有请求都走 Agent 会怎样？

**答浅的信号**：只列功能，不说自己负责哪层；说“用了 LangGraph”但说不出为什么。

### [重点] 2. `classify → route → act` 每一步的输入输出是什么？计划编译器校验什么？

**面试官想验证**：你是真的理解控制流，还是只会调框架。

**你的答题锚点**：

- `classify` 判断意图类别；`route` 产出目标和结构化计划；`act` 按计划执行。
- 编译器校验工具是否已注册、参数是否符合 Schema、依赖是否成环、是否越过写边界。
- 计划最多 8 步、3 层依赖、每批最多 3 个；知识库同名步骤串行。

**追问链**：模型提出未注册工具怎么办？某一步失败怎么办？两个步骤互相依赖怎么办？

**答浅的信号**：分不清 route 和 act；没有上限；把校验交给模型。

### [重点] 3. 写操作为什么必须人工确认？确认怎么做到幂等？状态不明为什么不自动重放？

**面试官想验证**：你有没有安全意识和可靠性设计。

**你的答题锚点**：

- 提议 → 审批 → 执行器；确认幂等并写审计。
- 状态不明时拒绝自动重放，要求人工核对。
- 场景动作由宿主执行并回传回执，没有回执不算成功。

**追问链**：用户双击确认怎么办？服务在确认后重启怎么办？怎么知道写操作到底有没有发生？

**答浅的信号**：只说“加个弹窗”；没有幂等、审计和状态核对。

### [重点] 4. 工具从 MCP 目录动态绑定，参数怎么校验？模型选错工具或参数怎么办？

**面试官想验证**：你是否理解运行时校验和工具边界。

**你的答题锚点**：

- 宿主/中台每次上报工具目录，模型只看到本次目录。
- 参数用 JSON Schema / Ajv 校验；缺参先问，不猜。
- 参数错误最多修两次，不能借机换工具；越权在调用前拦。

**追问链**：TypeScript 类型不够吗？MCP schema 变了怎么办？工具返回里带注入指令怎么办？

**答浅的信号**：相信模型会传对参数；没有运行时校验。

### [重点] 5. 会话、图状态、任务卡、审批、场景回执分别存什么？服务重启后怎么恢复？

**面试官想验证**：你是否真的处理过有状态 Agent。

**你的答题锚点**：

- 会话、图状态、任务卡、审批、场景回执存 PostgreSQL。
- 同一会话用咨询锁串行；支持跨轮续接和后台运行。
- 工单查询有已完成结果引用，恢复时不会重跑；状态不明只核对，不重放。

**追问链**：模型调用成功但 DB 写入失败怎么办？两条消息同时到达怎么办？会话怎么过期？

**答浅的信号**：只说“存 Redis”；没有会话锁、幂等和恢复语义。

### [重点] 6. Agent 怎么评测？L1/L2、交付判定、裁判、人工标注各自解决什么？

**面试官想验证**：你能不能证明系统没退化。

**你的答题锚点**：

- L1 固定断言：执行结果、安全拦截、数值溯源。
- L2 完成率、工具成功率、完整交付率。
- 裁判、人工标注、归因校准、回归草稿形成闭环；不达线阻断发布。

**追问链**：裁判有偏差怎么办？阈值怎么定？评测集是不是自己出题自己判？门禁误杀怎么办？

**答浅的信号**：只跑几个 case；没有指标、基线和门禁。

### [重点] 7. 讲一个你排查过的失败：现象、证据、根因、修复、复验。

**面试官想验证**：你的调试方法和诚实程度。

**你的答题锚点**：

- 江中：设备存在但无告警，仍需定位；或场景动作状态不明。
- ThingJS：目标类召回了，但没有进入最终上下文。
- 按“现象 → 证据 → 哪一层 → 改了什么 → 怎么复验”讲。

**追问链**：怎么复现？怎么证明修好了？有没有引入新问题？

**答浅的信号**：把问题归因于“网络”或“模型不稳定”；没有证据链。

### [重点] 8. 如果流量涨 10 倍，哪里先崩？怎么扩？

**面试官想验证**：你有没有系统扩展意识。

**你的答题锚点**：

- 限流在进程内；多实例要外置限流和状态。
- 会话锁、SSE 连接、模型网关排队、向量检索、成本都会先到瓶颈。
- 先看 P95、排队时间、首字延迟、工具失败率和单轮成本。

**追问链**：会话怎么分片？SSE 要不要粘性？成本怎么设上限？哪个指标最先报警？

**答浅的信号**：只说“加机器”；没有瓶颈排序和指标。

### [重点] 9. 你的项目里哪些真正生效，哪些是模拟或未验证？如果我说你只是套了 LangGraph，你怎么反驳？

**面试官想验证**：你是否诚实，能不能区分框架能力和自己的工程。

**你的答题锚点**：

- 三维只有聚焦、飞行、告警高亮真正改变场景；其余标记为模拟。
- 微调、分布式多实例没有生产验证。
- 反驳点：计划编译器、参数校验、审批幂等、场景回执、评测门禁都是自己补的，不是框架自带。

**追问链**：最难的一段代码是什么？如果重做会怎么改？最大的技术债是什么？

**答浅的信号**：把框架能力说成自己的；被追问就回避。

### [重点] 10. ThingJS RAG 为什么不用固定长度切块？混合检索、RRF、父块分别解决什么？

**面试官想验证**：你的 RAG 深度。

**你的答题锚点**：

- 按 Markdown 结构和代码 AST 切；保留类/成员身份和父块。
- 向量补语义，BM25 补精确符号；RRF 按排名融合。
- 精确符号置顶、父块回填、证据守卫；切块参数进入指纹。

**追问链**：怎么评估切块？类名写错怎么办？为什么不用 ANN？索引怎么不停服切换？

**答浅的信号**：只会说“用 splitter”；没有评估和版本概念。

### [重点] 11. RAG 生成怎么防幻觉？引用检查能保证什么，不能保证什么？

**面试官想验证**：你是否理解生成侧的可控性边界。

**你的答题锚点**：

- 结构化 JSON、回答形态分类、证据筛选、领域守卫、引用校验、无证据拒答、确定性清洗。
- 引用检查能保证“引用真实存在”，不能保证“引用支持结论”；后者要靠裁判和人工抽检。

**追问链**：引用存在但不对应怎么办？模型忽略证据怎么办？幻觉怎么量化？

**答浅的信号**：只在 Prompt 里写“不要编”；没有校验和评测。

### [重点] 12. 前端怎么处理 SSE、取消、背压、审批卡和会话恢复？

**面试官想验证**：你是不是“偏前端”的 AI 应用工程师。

**你的答题锚点**：

- `ReadableStream` + `TextDecoder` 解析 SSE；`delta/reset/phase/done/error` 事件。
- 增量预览不是最终答案，`done` 才是权威结果；`AbortController` 取消。
- 审批卡只产出 patch，不自己提交；会话恢复区分“没跑完”和“没保存”。
- Markdown 渲染 + XSS 净化；重试复用原气泡，避免重复消息。

**追问链**：为什么不用 WebSocket？`done` 一直不来怎么办？读得慢导致内存涨怎么办？SSE 怎么测？

**答浅的信号**：只会 EventSource；没有取消、错误和背压处理。

## 8. 怎么练

1. 每天 3 道 P0，录音 60–90 秒，只改一个毛病。
2. 每题必须带一个项目锚点和一句边界，避免空泛。
3. 周末按第 3 节的顺序做一次 30 分钟模拟面试。
4. 面试前只看这页和[考前清单](/04-面试题库/考前清单)，不要临时背新题。
