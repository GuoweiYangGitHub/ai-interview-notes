# 语言基础

> 来源：综合面试题 PY01–PY08、PB01–PB06。

## Python 项目追问与语言基础

**项目追问（8 题）**

### PY01｜江中助手发出一次模型请求，FastAPI 网关从收到请求到返回内容，经过哪些步骤？

**参考回答**

助手服务调用 OpenAI 兼容接口。模型网关检查调用凭证、模型权限和额度，然后尝试获取并发槽。槽满时进入有上限的等待队列，超时就结束等待。拿到槽后，网关通过 `httpx` 转发请求到 vLLM，再把流式响应传回助手服务。排查时按鉴权、排队、上游调用和响应传输分段看。

### [重点] PY02｜FastAPI 路由写了 `async def`，里面直接调用 `requests.post()`，并发上来会怎样？

**参考回答**

同步网络调用会占住处理这个协程的事件循环线程。同一循环里的其他协程也会受到影响。模型调用这类网络 I/O 可以用 `httpx.AsyncClient`。如果已有同步库，可以考虑把阻塞工作交给线程，并限制线程数。纯 Python 的 CPU 密集计算需要单独考虑进程或执行服务，`async` 本身不会让计算并行。

### [重点] PY03｜客户端中途断开，怎么关闭上游模型流、释放并发槽？

**参考回答**

先看服务端何时感知断开，以及取消能否传到流式转发协程。用 `async with` 管理上游流的生命周期，用 `try/finally` 归还已拿到的槽。并发槽要覆盖整个流式转发，收到上游响应头时还不能释放。排队中的请求取消时要从等待队列移除。关闭本端连接后，上游是否立刻停止推理取决于上游的取消支持。

### [重点] PY04｜等并发槽、连接 vLLM、等模型输出超时，有什么区别？

**参考回答**

排队超时发生在拿到并发槽之前。连接超时发生在建立上游连接时。流式读取超时通常是等下一块数据超时。整个请求的截止时间还要覆盖排队和后续各阶段。排查时用同一个请求编号对比入队、拿槽、发上游、收到首块和结束的时间。

### [重点] PY05｜并发限制和队列长度限制分别解决什么问题？

**参考回答**

并发槽控制同时占用上游资源的请求数。等待队列上限控制还允许积压多少请求。队列满时按接口约定快速失败。已入队的请求还要有等待期限，并处理客户端取消。面试时可以解释为什么队列变大可能增加等待时间，却不会直接提高推理吞吐。

### PY06｜模型有时返回 429，有时返回 200 但内容无法解析为 JSON，怎么处理？

**参考回答**

429 属于调用层限流，先看是否有重试提示和剩余时间，适合时才有限重试。HTTP 200 之后，要区分响应体解析失败、模型输出不符合约定结构，以及结构合法但业务内容错误。分别记录失败阶段，避免对相同输入一直重试。流式响应已经向客户端发出一部分后，重新请求可能造成重复输出。

### [重点] PY07｜智能问数为什么把 SQL 放在子进程，把模型生成的 Python 放在容器？

**参考回答**

SQL 侧用静态校验、独立子进程和只读连接限制查询，并设置超时和结果边界。模型生成的 Python 能尝试访问文件、网络或其他资源，执行时通过 Docker 限制网络、文件系统和资源。容器不可用时拒绝执行。解释项目时分别说清 SQL 和 Python 的隔离方式。

### PY08｜改了网关的超时或取消逻辑，怎么证明修好了？

**参考回答**

用可控上游分别模拟正常流、迟迟不返回、返回一半后中断。再做客户端主动断开的用例。除了检查客户端收到的结果，还要确认上游响应被关闭、等待队列或并发槽回到预期状态，以及下一条请求能继续执行。用请求编号和分段耗时定位失败阶段。

**语言基础（6 题）**

### PB01｜`b = a` 之后改 `b`，为什么 `a` 也变了？

**参考回答**

赋值让两个名字指向同一个对象。例如 `a = [[1]]; b = a`，通过任意一个名字修改列表都能从另一个名字看到。用 `b = a.copy()` 得到的是浅拷贝，外层列表独立，里面的小列表仍共享。需要隔离嵌套内容时，再考虑深拷贝或按字段复制。

### PB02｜为什么 `def collect(item, result=[])` 会把上一次的数据带进来？

**参考回答**

默认参数在函数定义时求值。同一个默认列表会被多次调用共享。把默认值改成 `None`，再在函数体里用 `if result is None` 创建新列表。调用方明确传入空列表时，仍按传入的对象处理。

### PB03｜`is` 和 `==` 有什么区别？

**参考回答**

`is` 判断两个名字是否指向同一个对象，`==` 判断值是否相等。两个分别创建的空列表相等，但不是同一个列表。判断空值通常写 `value is None`。

### PB04｜`try/except/finally` 和 `with` 分别什么时候用？

**参考回答**

`except` 处理预期异常，`finally` 在退出时做清理。文件、HTTP 响应这类资源通常已有上下文管理器，可以用 `with` 或 `async with` 管理获取与释放。自己拿到的并发槽可以在 `finally` 中归还。捕获异常时尽量明确异常类型，并保留排查需要的上下文。

### PB05｜调用 `async def` 为什么没有立即执行？怎么让多个工具请求并发？

**参考回答**

调用协程函数会得到协程对象。用 `await` 执行，或把它调度为任务。对互相独立的 I/O 请求，可以用 `asyncio.TaskGroup` 启动多个任务，再用 `asyncio.Semaphore` 限制同时调用数。还要决定某一路失败后是取消其余任务，还是分别收集结果并允许部分成功。

### PB06｜开发环境可以 `import`，容器里却提示找不到模块，怎么查？

**参考回答**

先用 `sys.executable` 确认服务实际使用的解释器，再用 `python -m pip show 包名` 检查同一环境里是否安装了依赖。然后检查容器构建时是否安装依赖、复制了源码，以及启动目录和包的导入路径是否正确。按容器实际的启动命令复现，区分第三方依赖缺失与项目模块路径错误。
