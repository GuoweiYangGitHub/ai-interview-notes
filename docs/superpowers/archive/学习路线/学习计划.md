## 每天固定动作

- **早上 20 分钟**：口述 3 道 P0 题，录音回听，只改一个问题。
- **中午 40 分钟**：读 1 个专题页，补 5 行自己的话术。
- **晚上 20 分钟**：把当天数字和追问写进[数字与话术](/04-面试题库/数字与话术)或项目问答页。

## 30 分钟路径

- [ ] 看[项目架构图](/03-项目实战/架构图)，说出两个项目各有哪些层。
- [ ] 用一分钟分别介绍两个 AI 项目：做什么、你负责什么、最难的一点。
- [ ] 用 60 秒介绍中国移动网络拓扑：3D/2D 布局、聚合下钻、相机。
- [ ] 读[简历主线](/00-学习路线/简历主线)，把 30 秒版本改成自己的话。

## 1 天路径

### 上午：前端

- [ ] JavaScript：原型、闭包、事件循环、Promise、手写题。
- [ ] TypeScript：泛型、条件类型、`keyof`/`typeof`、类型收窄。
- [ ] Vue/React：响应式、组件通信、生命周期、性能。

### 下午：AI 应用

- [ ] RAG：切片、Embedding、混合检索、精排、评测。
- [ ] Agent/MCP：工具设计、控制流、权限、取消与恢复。
- [ ] LangGraph：状态、节点、边、checkpoint、human-in-the-loop。

### 晚上：项目与讲法

- [ ] 两个 AI 项目各过一遍“关键取舍”和“高频追问”。
- [ ] 中国移动网络拓扑过一遍布局、相机、聚合下钻三类追问。
- [ ] 用[数字与话术](/04-面试题库/数字与话术)统一口径。

## 弱项补强

| 弱项 | 投入 | 目标 |
| --- | --- | --- |
| 微调 / 训练 | 半天 | 能说清什么时候该微调、什么时候用 RAG / Prompt，不冒充生产经验 |
| 分布式与多实例 | 半天 | 能讲清限流、状态外置、会话锁和扩展方案，说明尚未生产验证 |
| Python / FastAPI | 1 天 | 能读能改，能解释异步阻塞、超时取消和连接池 |
| 算法 | 按需 | 前端高频题够用，不往算法工程师方向包装 |

## 每周复盘

- 这周新增了哪 3 个能讲 60 秒的点？
- 哪个数字还说不清口径？
- 哪个追问还需要看项目页？
- 下周只改一个最弱的地方。
