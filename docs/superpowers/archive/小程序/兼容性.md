# 小程序兼容性
> 图片闪动变形与 `showLoading` 文案长度等小程序端兼容问题。

## 解决小程序图片闪动变形问题


- 如果设置了 `widthFix`，则手动将 `height` 调整为 `auto`。
- 如果设置了 `heightFix`，则手动将 `width` 调整为 `auto`。

```html
<style lang="scss">
  .widthFix {
    height: auto;
  }

  .heightFix {
    width: auto;
  }
</style>

<image
  class="widthFix"
  mode="widthFix"
  src="https://example.com/demo.jpg"
/>

<image
  class="heightFix"
  mode="heightFix"
  src="https://example.com/demo.jpg"
/>
```

## showLoading 展示问题

小程序 `wx.showLoading` 中 `title` 的值在安卓下只能显示最大 7 个字符，iOS 可以大于 7 个字符。
