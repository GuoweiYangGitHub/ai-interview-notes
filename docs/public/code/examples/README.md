# Agent 开发示例

查阅入口。先看总览，再进对应目录的 README。

密钥只配仓库根目录 `.env`（`BAILIAN_TOKEN_PLAN_API_KEY` / `CHAT_BASE_URL` / `CHAT_MODEL`）。各示例 `client.ts` 读环境变量，业务代码不读。新示例的 README 写法见 `.cursor/skills/example-readme/`。

| id  | 目录                                           | run                                                                         | when                                 |
| --- | ---------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------ |
| 01  | 01.定义模型结构化输出/                         | [`npm run 01`](01.定义模型结构化输出/README.md)                             | 要定义模型结果形状并验收时           |
| 02  | 02.多步流程编排与条件分支/                     | [`npm run 02`](02.多步流程编排与条件分支/README.md)                         | 一次请求会漏项、需要分段与分支时     |
| 03  | 03.模型规划并调用工具/                         | [`npm run 03`](03.模型规划并调用工具/README.md)                             | 模型要选工具、宿主执行并回传观察时   |
| 04  | 04.管理Agent的行动能力-注册、工具池与动态装载/ | [`npm run 04`](04.管理Agent的行动能力-注册、工具池与动态装载/README.md)     | 要注册、装载、按场景裁剪工具池时     |
| 05  | 05.MCP协议融入Agent/                           | [`npm run 05`](05.MCP协议融入Agent/README.md)                               | 工具在进程外、需发现再接入 Action 时 |
| 06  | 06.独立的运行环境设计（沙箱）/                 | [`npm run 06` / `06:01` … `06:05`](06.独立的运行环境设计（沙箱）/README.md) | 模型指令不能直接打进本机时           |
| 07  | 07.规划转任务，任务转Loop/                     | [`npm run 07`](07.规划转任务，任务转Loop/README.md)                         | 先出计划、再任务板、再循环收敛时     |
