## 案例设计

### F1. 通用浏览器自动化智能体

- 场景：动态页、反爬、传统 RPA 搞不定的比价 / 竞品。
- 链路：LangGraph 上 Planner–Executor–Reviewer；Playwright；DOM 失败走视觉坐标；代码进沙箱；工具 MCP 化。
- 坑：弹窗点不到、点完抓空白、生成代码不安全。

### F2. 企业级混合检索知识库

- 场景：金融 PDF / 研报，专名召回。
- 链路：BM25 + 向量 + Rerank；小规模可无向量库；短长期记忆；LangFuse + 黄金集看 Hit/MRR。
- 接到你：LanceDB + BM25 + RRF，门禁数字用自己的。
