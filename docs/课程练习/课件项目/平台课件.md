# 平台课件


---

> **课程案例练习**：用于展示方案拆解与技术选型，不代表真实商业项目或个人项目经历。

## 案例设计

每条围绕：场景、为什么选这套、模块怎么串、一个坑。它们用于说明“如果让我设计会怎么做”，不作为个人商业项目经历。

### E1. 市场舆情监测 Agent

**口述要点**

- 每日按日期抓证券新闻 + App 评论 → 热词 / 情感 → 词云 + 解读 → PDF 日报；人工汇编从小时级到分钟级。
- 主工作流嵌套子流程（新闻、评论、汇总出报），对外一次调用。
- 坑：多源字段不齐、情感标签要有依据、报告要带数据时间。

---

### E2. 私有化智能客服 ChatFlow（Dify）

**口述要点**

- 内网起 Dify 全家桶，模型走自建推理；数据不出域。
- ChatFlow：提问 → 意图 → RAG 或调 OA/CRM → 引用回答 / 低置信转人工。
- 分块 + Rerank；prompt 强制基于片段、无答案则转人工。
- 客服用 Chatflow（有状态）；批量解析文档用 Workflow。

---

### E3. ChatBI 金融问答助手

**口述要点**

- 自然语言 → 意图路由 → 取数 / SQL 工具 → Polars 算指标 → LLM 点评 + 图。
- 自定义 SQL 工具把「问句到可视化」收成一次工具调用；对比走势先归一化再画。
- 数值不交给 LLM 算；输出带非投资建议、来源、时间戳。
