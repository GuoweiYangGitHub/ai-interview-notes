# ThingJS RAG 能力关联


---

> 将通用技术概念映射到 ThingJS RAG 的实际实现；未实现的能力会明确标注边界。

## Agent 与工具调用

课件要你能讲：ReAct、反应式/深思、LangGraph、MCP vs FC、Multi-Agent、Browser Use、LangFuse、死循环和幻觉。

| 课件要听的      | 你怎么接                                                |
| --------------- | ------------------------------------------------------- |
| MCP             | ThingJS `/mcp`，和网页同一套检索；LDAP Token + 部门额度 |
| 混合检索 / 评估 | 双路 Top28、RRF、Hit 门禁；不报课件 86%                 |
| 哲学            | 知识更新走 RAG 不是微调；生成带引用；额度在检索前       |
| 沙箱 / 浏览器   | 没做就明确边界，讲原理 + 课件理解                       |
| 多 Agent        | 当前是单检索服务多入口，不是 Planner-Coder 集群         |
| 慢 / Trace      | 检索并发槽、超时；生成走云端 Chat                       |

## RAG 实现映射

聚焦架构、工具、评测和召回优化；所有表述以仓库实际实现为准。

| 课件要你讲的 | 你怎么接                                                                          |
| ------------ | --------------------------------------------------------------------------------- |
| 架构         | 离线：MD → 成员切 → LanceDB + BM25；在线：扩写 → 双路 → RRF → `/search` 或 `/ask` |
| 工具         | TypeScript、LangChain、LanceDB、MCP、Zod 引用；不是「只会 FAISS 教程」            |
| 召回         | 混合检索 + 近邻类名扩写 + Parent 扩展；empty/low 可重试                           |
| 评估         | 黄金集 Hit@k、false-empty、生成门禁，CI 失败回滚                                  |
| 最新名词     | GraphRAG 能对比即可；没上图就说 API 文档不需要社区摘要                            |
| 踩坑         | 固定长度切糊方法；query/doc 模型必须一致；k=60 的 RRF 不是「60 个类」             |
