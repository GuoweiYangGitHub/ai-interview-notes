# HTML

> HTML 负责页面结构与语义，这一页整理语义化、文档结构、meta、表单和 SEO 的要点，完整问答见[面试题](./面试题.md)。

## 语义化

用正确的标签做正确的事情：标题用 `h1`–`h6`，导航用 `nav`，正文用 `article`，独立区块用 `section`，页眉页脚用 `header` / `footer`。

语义化的收益：

- 让页面内容结构化，方便浏览器和搜索引擎解析。
- 没有 CSS 时也能以可读的文档格式呈现。
- 爬虫依赖标记判断上下文和关键词权重，利于 SEO。
- 源码分块清晰，便于团队阅读和维护。

常见语义标签：`article`、`section`、`nav`、`aside`、`header`、`footer`、`main`、`figure`、`figcaption`、`time`。

## 文档结构

### DOCTYPE

`DOCTYPE` 是 document type（文档类型）的缩写，写在文档最前面、`<html>` 标签之前，用来告诉浏览器按哪种 HTML / XHTML 规范解析页面。

- 严格模式（标准模式）：按 W3C 标准解析和呈现页面。
- 混杂模式（怪异模式 / 兼容模式）：浏览器按自己的宽松方式解析，向后兼容旧页面。
- HTML5 不基于 SGML，不需要引用 DTD，所以只写 `<!DOCTYPE html>` 即可；HTML 4.01 基于 SGML，必须引用 DTD。

### meta

`meta` 通过 `name` 描述页面信息，通过 `http-equiv` 模拟 HTTP 响应头。

| 属性 | 常见值 | 作用 |
| --- | --- | --- |
| `name` | `keywords` | 关键字 |
| `name` | `description` | 页面描述 |
| `name` | `viewport` | 视口设置，移动端适配必需 |
| `name` | `robots` | 搜索引擎索引方式 |
| `name` | `renderer` | 搜索引擎的渲染方式 |
| `name` | `revisit-after` | 搜索引擎的重访时间 |
| `http-equiv` | `content-Type` | 设定网页字符集 |
| `http-equiv` | `X-UA-Compatible` | 告知浏览器以何种方式渲染页面 |
| `http-equiv` | `cache-control` | 请求和响应的缓存机制 |
| `http-equiv` | `expires` | 网站过期时间 |
| `http-equiv` | `refresh` | 自动刷新并跳转到指定页面 |
| `http-equiv` | `set-Cookie` | 设置 Cookie |

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />

<!-- 相当于设置 HTTP 响应头 -->
<meta http-equiv="参数" content="具体的描述" />
```

### 元素分类

- 行内元素：不独占一行，不能直接设置宽高。如 `a`、`span`、`img`、`input`、`label`、`strong`、`em`、`code`。
- 块级元素：独占一行，可以设置宽高。如 `div`、`p`、`h1`–`h6`、`ul`、`ol`、`li`、`table`、`form`、`section`、`article`。
- 空（void）元素：没有闭合标签。常见的有 `br`、`hr`、`img`、`input`、`link`、`meta`；还有 `area`、`base`、`col`、`embed`、`param`、`source`、`track`、`wbr`。

## 表单

表单负责采集用户输入，核心元素是 `form`、`input`、`select`、`textarea`、`button`、`label`。

- `label` 的 `for` 绑定控件的 `id`，点击文字也能聚焦控件，同时提升可访问性。
- `input` 的 `type` 决定控件形态与校验规则：`text`、`password`、`radio`、`checkbox`、`file`、`submit`、`reset`，以及 HTML5 新增的 `date`、`time`、`email`、`url`、`search`、`number`、`range`、`color`。
- `button` 在表单内默认是 `submit`，只做普通按钮时要显式写 `type="button"`。
- 原生校验属性：`required`、`pattern`、`min` / `max`、`minlength` / `maxlength`、`placeholder`。

## SEO 要点

- 合理的 `title`、`description`、`keywords`：三者权重依次减小。`title` 突出页面重点，重要关键词靠前、出现不超过 2 次，不同页面要不同；`description` 高度概括页面内容，长度合适，不堆砌关键词；`keywords` 列出重要关键词即可。
- 语义化 HTML，符合 W3C 规范，让搜索引擎容易理解页面。
- 重要内容放在 HTML 前面：搜索引擎从上到下抓取，部分引擎对抓取长度有限制。
- 重要内容不要依赖 JS 输出：爬虫通常不执行 JS。
- 少用 `iframe`：搜索引擎不会抓取 `iframe` 中的内容。
- 非装饰性图片必须加 `alt`。
- 提高网站速度：速度是搜索排序的重要指标。

## 存储与 Cookie

- `cookie` 大小不超过 4KB，同源请求会自动携带，可在浏览器和服务器之间来回传递。
- `localStorage` 持久保存，浏览器关闭后不丢失，除非主动删除。
- `sessionStorage` 在当前浏览器窗口关闭后自动删除。
- 二者都不自动发送给服务器，容量通常有 5MB 或更大。

Cookie 的关键属性：`Domain`、`Path`、`Expires` / `Max-Age`、`HttpOnly`、`Secure`、`SameSite`。其中 `SameSite` 可取 `Strict`、`Lax`、`None`，Chrome 80 之后默认 `Lax`，用于降低 CSRF 风险。

> 详细对比与 SameSite 的完整说明见[面试题：cookies、sessionStorage 和 localStorage 的区别](./面试题.md#重点-cookies-sessionstorage-和-localstorage-的区别)。

## 浏览器渲染入口

从地址栏输入 URL 到页面显示，HTML 只是其中一环，完整链路包括 DNS 解析、TCP 连接、HTTP 请求、HTML/CSS 解析、DOM/CSSOM/Render 树构建、布局与绘制。详见[浏览器与网络：网络与HTTP](../04-浏览器与网络/网络与HTTP.md)。
