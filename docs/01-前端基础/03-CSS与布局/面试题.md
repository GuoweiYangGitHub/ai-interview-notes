# CSS 面试题

> 覆盖盒模型、BFC、Flex、显隐属性与 scoped 的问答；样式实现细节统一放在[知识点](./知识点.md)。

## 基础概念

### [重点] 盒子模型

```txt
一种是 IE 盒子模型 border-box：宽或高 = content + border + padding
一种是标准盒子模型 content-box：宽或高 = content
```

通过 `box-sizing: border-box` 或 `box-sizing: content-box` 切换。

### [重点] BFC 块级格式化上下文

**BFC 布局规则**

- 内部的 box 会在垂直方向一个接一个地放置。
- BFC 是页面上的一个隔离的独立容器。
- box 垂直方向的距离由 margin 决定，属于同一 BFC 的两个相邻元素 margin 会重叠。
- 每个元素的左边与包含盒子的左边相接触，即使存在浮动也如此。
- BFC 的区域不会与 float 重叠。
- 容器里面的子元素不会影响外面的元素，反之也是如此。
- 计算 BFC 的高度时，浮动元素也参与计算。

**哪些元素会生成 BFC**

- `float` 不为 `none`
- `position` 不为 `static` / `relative`
- `overflow` 不为 `visible`
- `display` 的值为 `table`、`table-cell`、`table-caption`
- 根元素

**怎么防止 margin 重叠**

`overflow: hidden;`

**BFC 的应用**

左侧或右侧固定，另一侧自适应：

```html
<style>
  .left {
    float: left;
  }
  .right {
    overflow: hidden;
  }
</style>
```

### [重点] 弹性布局 Flex

- `justify-content`：主轴对齐方式，取值 `flex-start | flex-end | center | space-between | space-around`。
- `align-items`：侧轴对齐方式，取值 `flex-start | flex-end | center | baseline | stretch`。
- `flex-direction`：改变主轴方向，取值 `row | row-reverse | column | column-reverse | initial | inherit`。`row` 是默认值，水平显示；`row-reverse` 与 `row` 相同但顺序相反；`column` 垂直显示；`column-reverse` 垂直显示但顺序相反。
- `flex-basis`：给 flex 布局盒子固定宽度，取值 `number | auto | initial | inherit`。
- `initial`：设置为默认值。
- `inherit`：从父元素继承该属性。

### [重点] flex: 1 是什么的缩写

`flex: 1` 是 `flex-grow`、`flex-shrink`、`flex-basis` 三个属性的缩写，完整写法是 `flex: 1 1 auto`。

- `flex-grow`：定义项目的放大比例，默认 0。
- `flex-shrink`：定义项目的缩小比例，默认 1。
- `flex-basis`：定义分配多余空间之前项目占据的主轴空间，默认 `auto`。

### [重点] opacity: 0、visibility: hidden、display: none 的区别

**空间占据**

- `display: none`：隐藏后不占据额外空间，会产生回流和重绘。
- `visibility: hidden` 或 `opacity: 0`：隐藏后仍占用空间，只会发生重绘。

**子元素继承**

- `display: none`：不会被子元素继承，父元素不在了，子元素也不会显示。
- `visibility: hidden`：会被子元素继承，子元素可以设置 `visibility: visible` 重新显示。
- `opacity: 0`：也会被子元素继承，但不能通过设置子元素 `opacity: 1` 使其重新显示。

**事件绑定**

- `display: none` 和 `visibility: hidden` 绑定的事件无法触发。
- `opacity: 0` 绑定的事件可以触发。

**过渡动画**

- `transition` 对 `display` 和 `visibility` 无效。
- `transition` 对 `opacity` 有效。

## 样式与实现

### scoped 的原理

带有 class 的标签会自动加上 `data-v-xxxxxxxx` 属性，`style` 里的所有样式会变成属性选择器。

这样能保证样式只作用于当前组件，不会影响其他组件；但无法保证不受其他组件样式影响，所以最好所有组件都使用 scoped。

`/deep/` 可以穿透子组件，需要和 CSS 预处理器及 scoped 一起使用。

### CSS 文本溢出

单行：

```css
overflow: hidden;
white-space: nowrap;
text-overflow: ellipsis;
```

多行：

```css
display: -webkit-box;
overflow: hidden;
text-overflow: ellipsis;
word-break: break-all;
-webkit-box-orient: vertical;
-webkit-line-clamp: 3;
```

多行文本溢出显示不全时，给元素添加父盒子并设置固定高度。完整代码见[知识点：文本溢出](./知识点.md#文本溢出)。

### 隐藏滚动条与自定义滚动条

```css
/* 隐藏 */
::-webkit-scrollbar {
  display: none;
}

/* 自定义 */
::-webkit-scrollbar {
  width: 8px;
  height: 8px;
  background-color: #fff;
}
::-webkit-scrollbar-thumb {
  border-radius: 4px;
  background-color: hsla(220, 4%, 58%, 0.5);
}
```

其他方式：给滚动区域设置负的 `margin-right` 溢出，父元素设置 `overflow: hidden`；也可以用 `div` 模拟滚动条。详见[知识点：滚动条](./知识点.md#滚动条)。

### 强制开启 GPU 渲染

给滑动元素加 `-webkit-transform: translateZ(0px)`，让它进入 GPU 合成层。完整示例见[知识点：强制开启 GPU 渲染](./知识点.md#强制开启-gpu-渲染)。

### 占据剩余高度

父盒子 `height: 100%` 或具体数值，设置 `display: flex; flex-direction: column;`；要占据剩余高度的子盒子设置 `flex: 1;`。详见[知识点：占据剩余高度](./知识点.md#占据剩余高度)。

### 让不定宽高的元素水平居中

实现方式包括绝对定位 + `transform`、`table`、Flex、`margin: auto`、`text-align: center`。完整代码见[知识点：让不定宽高的元素水平居中](./知识点.md#让不定宽高的元素水平居中)。

### 两边固定中间自适应

可用绝对定位、浮动 + `overflow: hidden`、Flex 三种方式。完整代码见[知识点：两边固定、中间自适应](./知识点.md#两边固定中间自适应)。

### 移动端 1px

`devicePixelRatio = 物理像素 / CSS 像素`。用伪元素 + `transform: scale` 把 300% 的边框缩回 1/3。代码见[兼容与跨端：移动端 1px 问题](./兼容与跨端.md#移动端-1px-问题)。

### 手机端表单元素的默认外观重置

```css
input {
  -webkit-appearance: none;
}
```

### font-weight: 500 在 Android 无效

系统字体不支持该字重：iOS 字体支持，Android 常用的微软雅黑、宋体不支持，所以 iOS 有效、Android 无效。详见[兼容与跨端](./兼容与跨端.md#font-weight-500-在-android-无效)。

### backdrop-filter 滤镜

大部分浏览器兼容（不考虑 IE），可实现高斯模糊、亮度、对比度、投影、灰度、色调、反相、透明度、饱和度、褐色等效果。完整列表见[知识点：backdrop-filter 背景滤镜](./知识点.md#backdrop-filter-背景滤镜)。

## CSS 真题

### 两个 div 的颜色分别是什么

```html
<style>
  .blue {
    color: blue;
  }
  .red {
    color: red;
  }
</style>

<div class="red blue">123</div>
<div class="blue red">123</div>
```

答案：两个 `div` 都是红色。

原因：两个选择器都是单个 class，优先级相同。class 属性里的书写顺序不影响优先级，样式表中后出现的规则覆盖前面的规则。`.red` 在 `.blue` 之后定义，所以最终生效的是 `color: red`。
