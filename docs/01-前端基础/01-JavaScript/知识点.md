# JavaScript 核心知识

> 汇总数据类型、原型、Map/Set、Symbol 与常用 API 的要点，题目练习见[面试题](./面试题.md)，设计模式见[设计模式](./设计模式.md)。

## 数据类型与判断

### 八种数据类型

- `number`：数字类型
- `string`：字符串类型
- `boolean`：布尔值类型
- `undefined`：未定义类型
- `null`：空值类型
- `object`：对象类型
- `symbol`：Symbol 类型
- `bigint`：大整数类型

前七种是原始类型（`symbol`、`bigint` 为 ES6 新增），`object` 是引用类型。

### 变量在内存中的存储

- 基本数据类型：存在栈内存里。
- 引用数据类型：指针存在栈内存，指向堆内存中的一块地址，内容存在堆内存中。
- 也有说法认为 JavaScript 所有数据都存放在堆内存中，栈里只保存引用。

### 判断数据类型

- `typeof xxx`：能判断 `number`、`string`、`undefined`、`boolean`、`object`、`function`、`symbol`、`bigint`；`typeof null` 是 `object`。
- `Object.prototype.toString.call(xxx)`：能判断大部分类型，返回 `[object Xxx]`。
- `Array.isArray(xxx)`：判断是否为数组。

`typeof null` 为 `object` 的原因：不同数据类型在底层都通过二进制表示，二进制前三位为 `000` 会被判断为 `object` 类型；`null` 底层全是 0，前三位也是 `000`，所以被判断为 `object`。

### Object.prototype.toString.call() 的返回结果

| 类型 | 调用 | 结果 |
| --- | --- | --- |
| `Map` | `Object.prototype.toString.call(new Map())` | `[object Map]` |
| `Set` | `Object.prototype.toString.call(new Set())` | `[object Set]` |
| `Array` | `Object.prototype.toString.call([])` | `[object Array]` |
| `Object` | `Object.prototype.toString.call({})` | `[object Object]` |
| `Symbol` | `Object.prototype.toString.call(Symbol())` | `[object Symbol]` |
| `RegExp` | `Object.prototype.toString.call(new RegExp())` | `[object RegExp]` |
| `Function` | `Object.prototype.toString.call(function () {})` | `[object Function]` |
| `Null` | `Object.prototype.toString.call(null)` | `[object Null]` |
| `Undefined` | `Object.prototype.toString.call(undefined)` | `[object Undefined]` |
| `NaN` | `Object.prototype.toString.call(NaN)` | `[object Number]` |

### valueOf 与 toString

1. `valueOf` 偏向于运算，`toString` 偏向于显示。
2. 对象转换时，优先调用 `valueOf`。
3. 强转字符串优先调用 `toString`，强转数字优先调用 `valueOf`。
4. 正常情况下，优先调用 `toString`。
5. 运算操作符情况下优先调用 `valueOf`。

调用 `valueOf`：

| 调用者 | 返回值 | 返回值类型 |
| --- | --- | --- |
| `Array` | 数组本身 | Array |
| `Date` | 毫秒数 | Number |
| `Function` | 函数本身 | Function |
| `Object` | 对象本身 | Object |
| `String` | 字符串 | String |

调用 `toString`：

| 调用者 | 返回值 | 返回值类型 |
| --- | --- | --- |
| `Array` | 数组转字符串，相当于 `Array.join()` | String |
| `Boolean` | 转字符串 `'true'`、`'false'` | String |
| `Date` | 字符串日期，如 `'Fri Dec 23 2016 11:24:47 GMT+0800 (中国标准时间)'` | String |
| `Number` | 数字字符串 | String |
| `Object` | `'[object Object]'` | String |
| `String` | 字符串 | String |

## 原型与构造函数

### 原型与原型链

- 所有的函数（包括构造函数）都是 `Function` new 出来的，原型都是 `Function.prototype`。
- 所有的原型对象都是 `Object`（构造函数）new 出来的，原型都是 `Object.prototype`。
- 当访问对象的属性时，先查自身，找不到就沿 `__proto__` 向上查找，直到 `Object.prototype`，这条链就是原型链。

### new 操作符做了什么

- 创建一个空对象。
- 让 `this` 指向该对象。
- 执行构造函数并给对象属性赋值，同时继承构造函数的原型。
- 判断构造函数是否有返回值：返回引用类型则返回该引用，返回值类型则返回新建的对象。

手动实现：

```js
function objectFactory() {
  var obj = new Object() // 从 Object.prototype 上克隆一个空对象
  var Constructor = [].shift.call(arguments) // 取得外部传入的构造器
  obj.__proto__ = Constructor.prototype // 指向正确的原型
  var ret = Constructor.apply(obj, arguments) // 借用构造器给 obj 设置属性
  return typeof ret === 'object' && ret !== null ? ret : obj
}
```

### instanceof 的原理

`A instanceof B` 判断 `B.prototype` 是否在 `A` 的原型链上：沿着 `A.__proto__` 和 `B.prototype` 查找，找到同一引用返回 `true`，否则返回 `false`。

### 箭头函数的特点

- 没有 `prototype` 属性。
- 不绑定 `this`，会捕获其所在上下文的 `this` 作为自己的 `this`。
- 不绑定 `arguments`，用剩余参数代替。
- 不能使用 `yield` 命令。
- 不能作为构造函数，不能用 `new` 创建箭头函数的实例。

### this 的指向

`this` 总是指着一个对象，具体指向哪个对象是在运行时基于函数的执行环境动态绑定的，而非函数声明时的环境。

- 普通函数调用：`this` 指向 `window`（严格模式下为 `undefined`）。
- 对象方法调用：`this` 指向调用该方法的对象。
- `new` 构造函数调用：`this` 指向新创建的实例。
- `setTimeout` / `setInterval` 回调：`this` 指向 `window`。
- 箭头函数：`this` 指向定义时所在的上下文（作用域）。
- `call` / `apply` / `bind`：`this` 指向传入的对象。

构造函数显式返回对象会覆盖 `this`：

```js
var MyClass = function () {
  this.name = 'name'
  return { name: 'anne' }
}

var obj = new MyClass()
console.log(obj.name) // anne
```

如果构造函数不显式返回数据，或返回非对象类型，则不会造成上述问题。

### 执行上下文与 JS 引擎

JS 引擎工作过程：

- 分词 / 词法分析：将字符串分解成有意义的代码块，这些代码块称为词法单元（token）。
- 解析 / 语法分析：将词法单元流转换成代表程序语法结构的树，即抽象语法树（AST）。
- 代码生成：将 AST 转换为可执行代码。

LHS 和 RHS：

- LHS：赋值操作的左侧。
- RHS：赋值操作的右侧。
- 注意并不一定指 `=` 的左右侧，赋值操作还有 `+=`、`-=`、`*=` 等形式。

变量对象：JS 代码进入执行上下文时，JS 引擎在内存中建立的一个对象，用来存放当前执行环境中的变量。

词法作用域：函数在定义时所在的作用域决定变量查找路径。函数执行上下文中找不到变量时，会到调用上下文、再往上一级查找，直到全局执行上下文；最后找不到就是 `undefined`。

### 匿名函数与 IIFE

匿名函数没有函数名：

```js
(function (x, y) {
  alert(x + y)
})(2, 3)
```

第一个括号把函数解析成表达式，第二个括号调用该匿名函数并传入参数。

匿名函数的缺点：

- 栈追踪中不会显示有意义的函数名，调试困难。
- 没有函数名时，函数需要引用自身只能使用已过期的 `arguments.callee`。
- 省略了对于代码可读性很重要的函数名。

### 原型上的属性遍历

`for...in` 会遍历对象自身及原型链上的可枚举属性。只遍历自身属性时用 `hasOwnProperty` 过滤：

```js
function Person(name) {
  this.name = name
}
Person.prototype.age = 23
const person = new Person('Sunshine_lin')

for (const key in person) {
  person.hasOwnProperty(key) && console.log(key)
} // name
```

## Map/Set

### Set

- 成员的值都是唯一的，没有重复值，类似于数组。
- 可以遍历。
- `Set.prototype.constructor`：Set 构造函数。
- `Set.prototype.size`：返回 Set 实例的成员总数。
- `add(value)`：添加某个值，返回 Set 结构本身。
- `delete(value)`：删除某个值，返回布尔值，表示是否成功。
- `has(value)`：返回布尔值，表示参数是否为 Set 成员。
- `clear()`：清除所有成员，没有返回值。

特殊情况：

- `+0` 与 `-0` 在存储判断唯一性时恒等，所以不重复。
- `undefined` 与 `undefined` 恒等，所以不重复。
- `NaN` 与 `NaN` 不恒等，但在 Set 中只能存一个。

```js
let mySet = new Set()
mySet.add(1)
mySet.add(5)
mySet.add('some Text')
console.log(mySet) // 1, 5, 'some Text'

var mySet = new Set([1, 2, 3, 4, 5, 5]) // [1, 2, 3, 4, 5]

// 并集
var a = new Set([1, 2, 3])
var b = new Set([4, 3, 2])
var union = new Set([...a, ...b]) // {1, 2, 3, 4}

// 交集
var intersect = new Set([...a].filter((x) => b.has(x))) // {2, 3}

// 差集
var difference = new Set([...a].filter((x) => !b.has(x))) // {1}
```

### Map

- 键值对的集合，键和值都可以是任意类型。
- 可以遍历。
- 常用方法：`set()`、`get()`、`has()`、`delete()`。

```js
let map = new Map()
let map2 = new Map([
  ['key', 'value'],
  ['key2', 'value2']
])
```

开发中涉及数据结构时，能使用 Map 就不使用 Array，尤其是复杂的数据结构；如果对数组存储考虑唯一性，使用 Set，放弃 Array。

## Symbol

`Symbol` 表示唯一值，常用作对象的唯一属性名。除了创建普通 Symbol，ES6 还提供了一批内置 Symbol（well-known symbols）来自定义对象行为。

### Symbol.hasInstance

作用：自定义 `instanceof`。

```js
class Array1 {
  static [Symbol.hasInstance](instance) {
    console.log(instance, 'instance')
    return Array.isArray(instance)
  }
}

console.log([] instanceof Array1) // true
```

### Symbol.isConcatSpreadable

作用：控制作为 `Array.prototype.concat()` 参数时是否展开数组元素。

```js
var alpha = ['a', 'b', 'c']
var numeric = [1, 2, 3]

numeric[Symbol.isConcatSpreadable] = false
console.log(alpha.concat(numeric)) // ['a', 'b', 'c', [1, 2, 3]]

numeric[Symbol.isConcatSpreadable] = true
console.log(alpha.concat(numeric)) // ['a', 'b', 'c', 1, 2, 3]
```

### Symbol.iterator

作用：为对象创建一个默认迭代器，可被 `for...of` 循环使用。

```js
const myIterable = {}
myIterable[Symbol.iterator] = function* () {
  yield 1
  yield 2
  yield 3
}

console.log([...myIterable]) // [1, 2, 3]
```

也可以在类中作为计算属性：

```js
class Foo {
  *[Symbol.iterator]() {
    let i = 0
    yield i++
    yield i++
  }
}

console.log(...new Foo()) // 0 1
```

### Symbol.match

作用：指定对象是否按正则表达式匹配，而不是按字符串匹配。

```js
// 正常会报错，因为 /bar/ 是一个正则表达式
'/bar/'.startsWith(/bar/)

// 自定义匹配行为
var reg = /bar/
reg[Symbol.match] = false

'/bar/'.startsWith(reg) // true
'/abc/'.startsWith(reg) // false
```

### Symbol.matchAll

作用：根据字符串生成正则表达式的匹配项。

```js
const str = '2016-01-02|2019-03-07'

const numbers = {
  *[Symbol.matchAll](str) {
    for (const n of str.matchAll(/[0-9]+/g)) {
      yield n[0]
    }
  }
}

const arr = Array.from(str.matchAll(numbers))
console.log(arr)
```

### 字符串截取：substr 与 substring

`substr(startIndex, length)` 从 `startIndex` 返回子字符串，并返回 `length` 个字符：

```js
var s = 'hello'
s.substr(1, 4) === 'ello' // true
```

`substring(startIndex, endIndex)` 返回从 `startIndex` 到 `endIndex - 1` 的子字符串：

```js
var s = 'hello'
s.substring(1, 4) === 'ell' // true
```

### 日期转 ISO 标准

`toISOString()` 用于把 JS Date 对象转换为 ISO 标准字符串。

```js
var date = new Date()
var n = date.toISOString()
console.log(n) // YYYY-MM-DDTHH:mm:ss.sssZ
```

### URL 编码与解码

`encodeURI()` 对 URL 进行编码。它不会编码 `/ ? : @ & = + $ #`；如果需要编码这些字符，使用 `encodeURIComponent()`。

```js
var uri = 'my profile.php?name=sammer&occupation=pāntiNG'
var encoded_uri = encodeURI(uri)

decodeURI(encoded_uri)
```

### parseInt 与进制转换

`parseInt(string, radix)` 解析字符串并返回整数。`radix` 取值 2–36；为 0 或未设置时，JS 会根据 `string` 判断基数：

- 以 `0x` 开头：按十六进制解析其余部分。
- 以 `0` 开头：ECMAScript v3 允许实现按八进制或十六进制解析。
- 以 `1`–`9` 开头：按十进制解析。

进制计算方式：`xyz(n) = x*n^2 + y*n^1 + z`，`abxyz(n) = a*n^4 + b*n^3 + x*n^2 + y*n^1 + z`。

```js
parseInt('10', 9) // 1*9^1 + 0*9^0 = 9

parseInt('fdfsdkl234', 16)
// 剔除 s 及其后面的字符，有效部分为 fdf
// f=15, d=13, f=15
// 15*16^2 + 13*16^1 + 15*16^0 = 4063
```

经典题 `['0x1', '0x2', '0x3'].map(parseInt)`：`map` 会传入 `item`、`index`、`self` 三个参数，等价于：

```js
parseInt('0x1', 0) // radix 为 0，按十进制：1
parseInt('0x2', 1) // radix 1 无效：NaN
parseInt('0x3', 2) // 以二进制解析 '0x3'，x 不是合法二进制字符，只解析到 0：0
// 结果：[1, NaN, 0]
```

### FileReader 读取文件

```js
let reader = new FileReader()

reader.onload = (ev) => {
  try {
    const result = JSON.parse(ev.target.result)
    console.log(result)
  } catch (e) {
    console.log(e)
  }
}
```

事件：

- `onloadstart`：读取文件开始时触发。
- `onprogress`：读取过程中触发，返回本次读取的最大字节数和已读取字节数，可用于进度条。
- `onabort`：读取中断时触发。
- `onerror`：读取文件失败时触发。
- `onload`：读取完成时触发。
- `onloadend`：读取结束后触发，不论成功还是失败都会触发，时机在 `onload` 之后。

### DOMParser 解析 DOM

将存储在字符串中的 XML 或 HTML 源代码解析为一个 DOM：

```js
new DOMParser().parseFromString(str, 'text/html')
```

### AbortController 中断请求

表示一个控制器对象，允许根据需要中止一个或多个 Web 请求。

```js
const controller = new AbortController()
const signal = controller.signal

// 终止请求
controller.abort()

function fetchVideo() {
  const controller = new AbortController()
  const signal = controller.signal
  fetch(url, { signal })
    .then((response) => {
      console.log(response)
    })
    .catch((err) => {
      console.error(err)
    })
}
```

当 `abort()` 被调用时，`fetch()` 返回的 Promise 会 reject 一个名为 `AbortError` 的 DOMException。

- `controller.signal`：返回一个 `AbortSignal` 实例，可建立通信也可终止通信。
- `controller.abort()`：在 DOM 请求完成之前中止它，能中止 fetch 请求、各种响应主体或流的消耗。
- `AbortSignal.timeout(ms)`：指定时间后自动中止的 `AbortSignal`。

```js
try {
  const res = await fetch(url, { signal: AbortSignal.timeout(5000) })
} catch (e) {}
```
