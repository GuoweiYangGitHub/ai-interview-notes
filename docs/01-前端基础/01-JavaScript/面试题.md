## 数据类型与类型转换

### JavaScript 有几种数据类型

- `number`：数字类型
- `string`：字符串类型
- `boolean`：布尔值类型
- `undefined`：未定义类型
- `null`：空值类型
- `object`：对象类型
- `symbol`：Symbol 类型
- `bigint`：大整数类型

### 如何判断数据类型

- `typeof xxx`：能判断出 `number`、`string`、`undefined`、`boolean`、`object`、`function`（`null` 是 `object`）。
- `Object.prototype.toString.call(xxx)`：能判断出大部分类型。
- `Array.isArray(xxx)`：判断是否为数组。

类型判断的完整对照表见[知识点：Object.prototype.toString.call() 的返回结果](./知识点.md#object-prototype-tostring-call-的返回结果)。

### 为什么 typeof null 是 object

不同的数据类型在底层都通过二进制表示，二进制前三位为 `000` 会被判断为 `object` 类型。`null` 底层的二进制全都是 0，前三位肯定也是 `000`，所以被判断为 `object`。

### null 和 undefined 的异同点

相同点：

- 都是空变量。
- 都是假值，转布尔值都是 `false`。
- `null == undefined` 为 `true`。

不同点：

- `typeof` 判断 `null` 为 `object`，判断 `undefined` 为 `undefined`。
- `null` 转数字为 `0`，`undefined` 转数字为 `NaN`。
- `null` 是一个对象未初始化，`undefined` 是初始化了但未定义赋值。
- `null === undefined` 为 `false`。

### NaN 是什么？有什么特点

- `NaN` 不等于自身，也就是 `NaN === NaN` 为 `false`。
- `NaN` 为假值，转布尔值为 `false`。
- `NaN` 本质是一个 number，`typeof NaN === 'number'`。

### isNaN 与 Number.isNaN 的区别

- `isNaN`：除了判断 `NaN` 为 `true`，还会把不能转成数字的值判断为 `true`，例如 `'xxx'`。
- `Number.isNaN`：只有判断 `NaN` 时为 `true`，其余情况都为 `false`。

### == 与 === 的区别

- `==`：在比较过程中会存在隐式转换。
- `===`：需要类型相同、值相同，才能为 `true`。

### JavaScript 的隐式转换规则

1. 转成 string 类型：`+`（字符串连接符）。
2. 转成 number 类型：`++` / `--`（自增自减运算符）、`+ - * / %`（算术运算符）、`> < >= <= == != === !==`（关系运算符）。
3. 转成 boolean 类型：`!`（逻辑非运算符）。

### 双等号左右两边的转换规则

1. `null == undefined` 为 `true`。
2. 如果有一个操作数是布尔值，则在比较相等性之前先将其转换为数值：`false` 转换为 0，`true` 转换为 1。
3. 如果一个操作数是字符串，另一个操作数是数值，在比较相等性之前先将字符串转换为数值。
4. 如果一个操作数是对象，另一个操作数不是，则调用对象的 `toString()` 方法，用得到的基本类型值按照前面的规则进行比较。

### undefined >= undefined 为什么是 false

按照隐式转换规则，可转换成 `NaN >= NaN`。`NaN` 不等于 `NaN`，也不大于，所以是 `false`。

### null >= null 为什么是 true

按照隐式转换规则，可转换成 `0 >= 0`。0 等于 0，所以是 `true`。

### [] == ![] 为什么是 true

按照双等号的转换规则：

1. `!` 优先级高于 `==`，`[]` 不是假值，所以先转换成 `[] == false`。
2. 右边为布尔值，`false` 先转数字 0，所以可转换为 `[] == 0`。
3. 左边为对象，`[]` 调用 `toString` 转为 `''`，转换为 `'' == 0`。
4. 左边为字符串，`''` 转换为 0，最终为 `0 == 0`。

### 0.1 + 0.2 === 0.3，对吗

不对，JavaScript 的计算存在精度丢失问题。

```js
console.log(0.1 + 0.2 === 0.3) // false
```

- 原因：JavaScript 中小数是浮点数，需要转二进制进行运算。有些小数无法用二进制表示，只能取近似值，所以造成误差。
- 解决方法：先变成整数运算，然后再变回小数；`toFixed()` 性能不好，不推荐。

### JavaScript 变量在内存中具体存储形式

- 基本数据类型：存在栈（stack，先进后出）里。
- 引用数据类型：指针存在栈内存，指向堆（heap，数据任意存放）内存中的一块地址，内容存在堆内存中。
- 也有说法认为 JavaScript 所有数据都存堆内存中。

### JavaScript 的装箱和拆箱

**装箱**：把基本数据类型转化为对应的引用数据类型。

```js
const s1 = 'Sunshine_Lin'
const index = s1.indexOf('_')
console.log(index) // 8
```

`s1` 只是基本数据类型，之所以能调用 `indexOf`，是因为 JavaScript 内部做了装箱：

1. 创建 `String` 类型的一个实例。
2. 在实例上调用指定的方法。
3. 销毁这个实例。

```js
var temp = new String('Sunshine_Lin')
const index = temp.indexOf('_')
temp = null
console.log(index) // 8
```

**拆箱**：将引用数据类型转化为对应的基本数据类型，通过 `valueOf` 或 `toString` 方法实现。

```js
var objNum = new Number(123)
var objStr = new String('123')
console.log(typeof objNum) // object
console.log(typeof objStr) // object
console.log(typeof objNum.valueOf()) // number
console.log(typeof objStr.valueOf()) // string
console.log(typeof objNum.toString()) // string
console.log(typeof objStr.toString()) // string
```

### var、let、const 的区别

从四个方面区分：变量提升、块级作用域、重复声明同名变量、重新赋值。

- `var`：有变量提升，没有块级作用域，可以重复声明，可以重新赋值。
- `let`：有暂时性死区，有块级作用域，不能重复声明，可以重新赋值。
- `const`：有暂时性死区，有块级作用域，不能重复声明，声明时必须初始化且不能重新赋值（引用类型内部属性可改）。

### Object.is() 对比两个参数是否相等

```js
Object.is(NaN, NaN) // true
Object.is(+0, -0) // false
```

自己实现一个 `Object.is`：

```js
if (!Object.is) {
  Object.is = function (x, y) {
    if (x === y) {
      // +0 与 -0 不相等
      return x !== 0 || 1 / x === 1 / y
    } else {
      // NaN 与 NaN 相等
      return x !== x && y !== y
    }
  }
}
```

### parseInt 与进制转化

- `parseInt()` 解析一个字符串并返回一个整数。
- 当参数 `radix` 的值为 0 或没有设置时，`parseInt()` 会根据 `string` 判断数字的基数。
- 忽略 `radix` 时，JavaScript 默认基数如下：
  - 以 `0x` 开头：把其余部分解析为十六进制整数。
  - 以 `0` 开头：ECMAScript v3 允许实现把其后字符解析为八进制或十六进制数字。
  - 以 `1`–`9` 开头：解析为十进制整数。
- `radix` 取值 2–36。

进制计算方式：`xyz(n) = x*n^2 + y*n^1 + z`，`abxyz(n) = a*n^4 + b*n^3 + x*n^2 + y*n^1 + z`。

```js
parseInt('10', 9) // 1*9^1 + 0*9^0 = 9

parseInt('fdfsdkl234', 16)
// 剔除 s 及后面的字符，有效部分为 fdf
// 15*16^2 + 13*16^1 + 15*16^0 = 4063
```

面试题 `['0x1', '0x2', '0x3'].map(parseInt)`：

```js
// map 默认传入 item、index、self 三个参数
parseInt('0x1', 0) // radix 为 0，按十进制：1
parseInt('0x2', 1) // radix 1 无效：NaN
parseInt('0x3', 2) // 按二进制解析，x 非法，只解析到 0：0
// 结果：[1, NaN, 0]
```

## 函数、闭包与作用域

### [重点] 闭包是什么

闭包是一个能读取其他函数内部变量的函数。

更完整的定义：函数在定义时的词法作用域以外的地方被调用，并且访问了外部函数的局部变量，就会产生闭包。创建闭包的常见方式是在一个函数内部创建另一个函数。

```js
function a() {
  let num = 0

  // 这是个闭包
  return function () {
    return ++num
  }
}
const b = a()
console.log(b()) // 1
console.log(b()) // 2
```

用处：

- 可以减少全局变量的定义，避免全局变量污染。
- 可以读取函数内部的变量。
- 可以在内存中维护一个变量，用做缓存。
- 可以使用闭包模拟私有化方法。

问题：

- 增加一定的内存消耗，使用不当容易造成内存泄漏。
- 闭包可能在父函数外部改变父函数内部变量的值。
- 造成性能损失。

可以在控制台 `sources` → `Call Stack` → `Closure` 查看是否产生了闭包。

### 什么是变量提升？函数提升

变量提升：

```js
console.log(name) // undefined
var name = 'Sunshine_Lin'

if (false) {
  var age = 23
}
console.log(age) // undefined，不会报错
```

函数提升：

```js
console.log(fun) // function fun() {}
function fun() {}

if (false) {
  function fun2() {}
}
console.log(fun2) // undefined，不会报错
```

函数提升优先级 > 变量提升优先级：

```js
console.log(fun) // function fun() {}
var fun = 'Sunshie_Lin'
function fun() {}
console.log(fun) // 'Sunshie_Lin'
```

### 函数声明和函数表达式的区别

- 函数声明：享受函数提升。
- 函数表达式：归类于变量声明，享受变量提升。
- 函数提升优先级 > 变量提升优先级。

```js
console.log(fun) // fun () {}
// 函数表达式
var fun = function (name) {}
// 函数声明
function fun() {}
console.log(fun) // fun (name) {}
```

### 什么是匿名函数

匿名函数就是没有函数名的函数：

```js
;(function (x, y) {
  alert(x + y)
})(2, 3)
```

这里创建了一个匿名函数（第一个括号内），第二个括号用于调用该匿名函数并传入参数。

### 预编译

```js
var AO = {
  a: function a() {
    console.log('函数a')
  },
  d: 'abc'
}
```

1. 创建 AO 对象。
2. 找形参和变量声明，将变量和形参作为 AO 属性名，值为 `undefined`。
3. 将实参和形参相统一。
4. 在函数体里找到函数声明，值赋予函数体。最后程序输出变量值时，就是从 AO 对象中拿。

### 什么叫变量对象

变量对象是 JS 代码进入执行上下文时，JS 引擎在内存中建立的一个对象，用来存放当前执行环境中的变量。

### 词法作用域（Lexical scope）

函数执行上下文和全局执行上下文中都有变量。JavaScript 查找变量时，如果在函数执行上下文中找不到，就在调用上下文中寻找；如果调用上下文中也没有，就一直往上一级找，直到全局执行上下文。如果最后找不到，就是 `undefined`。

### 箭头函数与普通函数的区别

- 箭头函数中的 `this` 在编写代码时就已经确定，即箭头函数本身所在的作用域；普通函数在调用时确定 `this`。
- 箭头函数没有 `arguments`。
- 箭头函数没有 `prototype` 属性。
- 箭头函数不能作为构造函数，不能用 `new` 创建实例。

### 什么是纯函数？什么是函数副作用

- 纯函数：没有副作用的函数。
- 函数副作用：函数在正常工作任务之外对外部环境所施加的影响。

### 解释一下 "use strict"

`"use strict"` 是 ES5 引入的 JS 指令，目的是强制代码在严格模式下执行。严格模式下不能在不声明变量的情况下使用变量。早期版本的 JS 会忽略 `"use strict"`。

### require 和 import 的区别

- `require` 是运行时调用；`import` 是编译时调用，所以必须放在文件开头。
- `require` 是同步加载模块；`import` 是异步加载模块（有一个独立模块依赖的解析阶段）。
- `require` 输出的是一个值的（浅）拷贝；`import` 输出的是值的引用。
- 本质区别：
  - `require` 是赋值过程，结果就是对象、数字、字符串、函数等，再把结果赋值给某个变量。
  - `import` 是解构过程。在 Node 中使用 Babel 支持 ES6，也只是把 ES6 转码为 ES5 再执行，`import` 语法会被转换成 `require`。

## 原型与 this

### [重点] 原型与原型链

- 所有的函数（包括构造函数）都是 `Function` new 出来的，原型都是 `Function.prototype`。
- 所有的原型对象都是 `Object`（构造函数）new 出来的，原型都是 `Object.prototype`。
- 访问对象属性时，先查自身，找不到就沿 `__proto__` 向上查找，直到 `Object.prototype`，这条链就是原型链。

### instanceof 的原理

`A instanceof B` 判断 `B.prototype` 是否在 `A` 的原型链上。完整解释见[知识点：instanceof 的原理](./知识点.md#instanceof-的原理)。

### [重点] new 操作符做了什么

- 创建了一个空对象。
- 让 `this` 指向了该对象。
- 执行构造函数并给对象的属性赋值，继承构造函数的原型。
- 判断构造函数是否有返回值，并根据返回值类型进行返回：引用类型返回引用地址，值类型返回新建的对象。

手动实现：

```js
function objectFactory() {
  var obj = new Object()
  var Constructor = [].shift.call(arguments)
  obj.__proto__ = Constructor.prototype
  var ret = Constructor.apply(obj, arguments)
  return typeof ret === 'object' && ret !== null ? ret : obj
}
```

### [重点] this 指向（函数的 4 种调用模式）

- 普通函数调用：`this` 指向 `window`。
- 对象调用：`this` 指向调用的这个对象。
- `new` 构造函数调用：`this` 指向 new 构造函数的实例。
- `setTimeout` / `setInterval`：`this` 指向 `window`。
- 箭头函数：`this` 指向上下文（即作用域）。
- `call` / `apply`：`this` 指向你要替换的对象。

### 面向对象

运用类、继承、封装等进行程序设计的一种思想。

- 能够将复杂问题和复杂逻辑简单化。
- 方便扩展。
- 方便维护。

### Reflect 对象

`Reflect` 对象与 `Proxy` 对象一样，是 ES6 为了操作对象而提供的新 API。

- `Reflect.get(target, name, receiver)`：查找并返回 `target` 对象的 `name` 属性，如果没有该属性则返回 `undefined`。
- `Reflect.set(target, name, value, receiver)`：设置 `target` 对象的 `name` 属性等于 `value`。

```js
// proxy 代理
const target = {
  name: 'yang',
  sex: 'man'
}
const handler = {
  get(target, key) {
    console.log('获取名字')
    return Reflect.get(target, key)
  },
  set(target, key, value) {
    return Reflect.set(target, key, `强行设置为${value}`)
  }
}
const proxy = new Proxy(target, handler)
console.log(proxy.name)
// 获取 name 属性时先进入 get 方法，打印“获取名字”，
// 再通过 Reflect.get(target, key) 拿到属性值，相当于 target[key]
```

`Proxy` 会改变 `target` 中的 `this` 指向：一旦 `Proxy` 代理了 `target`，`target` 内部的 `this` 就指向 `Proxy` 代理。

```js
const target = new Date('2021-01-01')
const handler = {
  get(target, prop) {
    if (prop === 'getDate') {
      return target.getDate.bind(target) // 重新绑定 this 指向
    }
    return Reflect.get(target, prop)
  }
}
const proxy = new Proxy(target, handler)
console.log(proxy.getDate())
```

## 事件循环与异步

### [重点] 事件循环（Event Loop）

JavaScript 是单线程的，同步代码在执行栈中执行，异步任务进入任务队列。

一次事件循环的流程：

1. 执行执行栈中的同步代码。
2. 清空微任务队列（`Promise.then/catch/finally`、`queueMicrotask`、`MutationObserver` 等）。
3. 取出一个宏任务（`setTimeout`、`setInterval`、I/O、UI 交互事件等）执行。
4. 再次清空微任务队列，然后进入下一轮循环。

同一个事件循环中，微任务总是先于下一个宏任务执行。

### 处理异步的方法有哪些

- 回调函数
- Promise
- 事件监听
- 发布订阅
- async / await

### Ajax、Axios、Fetch 有啥区别

- Ajax：是对 `XMLHttpRequest` 对象（XHR）的封装。
- Axios：是基于 Promise 对 XHR 对象的封装。
- Fetch：是 `window` 的一个方法，也基于 Promise，但与 XHR 无关，不支持 IE。

### load、$(document).ready、DOMContentLoaded 的区别

DOM 文档加载的步骤：

1. 解析 HTML 结构。
2. 加载外部脚本和样式表文件。
3. 解析并执行脚本代码。
4. DOM 树构建完成 → `DOMContentLoaded` 触发、`$(document).ready` 触发。
5. 加载图片等外部文件。
6. 页面加载完毕 → `load` 触发。

## 数组、对象与常用 API

### 数组相关的小知识

- `map()` 没有 `return` 时，返回值为 `undefined`。
- `sort()` 默认按 ASCII 码排序。
- `push()` 返回值为数组的新长度。

### 如何实现数组去重

```js
// 使用 Map 去重
function quchong1(arr) {
  const newArr = []
  arr.reduce((pre, next) => {
    if (!pre.get(next)) {
      pre.set(next, 1)
      newArr.push(next)
    }
    return pre
  }, new Map())
  return newArr
}

// 使用 Set 去重
function quchong(arr) {
  return [...new Set(arr)]
}
```

### 解决遍历对象时把原型上的属性遍历出来的问题

使用 `hasOwnProperty` 判断：

```js
function Person(name) {
  this.name = name
}
Person.prototype.age = 23
const person = new Person('Sunshine_lin')

for (const key in person) {
  console.log(key)
} // name age

for (const key in person) {
  person.hasOwnProperty(key) && console.log(key)
} // name
```

### 如何将 JS 日期转换为 ISO 标准

`toISOString()` 方法用于将 JS 日期转换为 ISO 标准，它使用 ISO 标准将 JS Date 对象转换为字符串。

```js
var date = new Date()
var n = date.toISOString()
console.log(n) // YYYY-MM-DDTHH:mm:ss.sssZ
```

### 如何在 JS 中编码和解码 URL

`encodeURI()` 对 URL 进行编码。注意它不会编码 `/ ? : @ & = + $ #`，如果需要编码这些字符，请使用 `encodeURIComponent()`。

```js
var uri = 'my profile.php?name=sammer&occupation=pāntiNG'
var encoded_uri = encodeURI(uri)

decodeURI(encoded_uri)
```

### substr() 和 substring() 有什么区别

`substr(startIndex, length)` 从 `startIndex` 返回子字符串，并返回 `length` 个字符：

```js
var s = 'hello'
s.substr(1, 4) == 'ello' // true
```

`substring(startIndex, endIndex)` 返回从 `startIndex` 到 `endIndex - 1` 的子字符串：

```js
var s = 'hello'
s.substring(1, 4) == 'ell' // true
```

## BOM 与 DOM

### 绑定点击事件有几种方式

三种：

- `xxx.onclick = function () {}`
- `<xxx onclick=""></xxx>`
- `xxx.addEventListener('click', function () {}, false)`

`addEventListener` 的第三个参数传一个布尔值，表示是否需要阻止冒泡，默认是 `false`，不阻止冒泡。

### [重点] JavaScript 的事件流模型有哪些

- 事件冒泡：由最具体的元素接收，并往上传播。
- 事件捕获：由最不具体的元素接收，并往下传播。
- DOM 事件流：事件捕获 → 目标阶段 → 事件冒泡。

### 如何阻止事件冒泡

```js
function stopBubble(e) {
  if (e.stopPropagation) {
    e.stopPropagation()
  } else {
    window.event.cancelBubble = true
  }
}
```

### 如何阻止事件默认行为

```js
function stopDefault(e) {
  if (e.preventDefault) {
    e.preventDefault()
  } else {
    window.event.returnValue = false
  }
}
```

### [重点] 什么是事件委托

当所有子元素都需要绑定相同事件时，可以把事件绑定在父元素上，这就是事件委托。

优点：

- 绑定在父元素上只需要绑定一次，节省性能。
- 子元素不需要每个都去绑定同一事件。
- 如果后续又有新的子元素添加，会由于事件委托自动接收到父元素的事件监听。

### BOM 和 DOM 的关系

- BOM 全称 Browser Object Model，即浏览器对象模型，主要处理浏览器窗口和框架。
- DOM 全称 Document Object Model，即文档对象模型，是 HTML 和 XML 的应用程序接口（API），遵循 W3C 标准，所有浏览器公共遵守。
- JS 通过访问 BOM 对象来访问、控制、修改客户端（浏览器）。BOM 的 `window` 包含 `document`，`window` 对象的属性和方法可以直接使用，因此可以直接使用 `window.document`，通过它访问、检索、修改文档内容与结构。`document` 对象又是 DOM 的根节点。
- 可以说 BOM 包含了 DOM 对象：浏览器提供 BOM 对象供访问，从 BOM 对象再访问到 DOM 对象，从而 JS 可以操作浏览器以及浏览器读取到的文档。

### 讲讲 JavaScript 的垃圾回收机制

现代浏览器使用标记清除法：假定设置一个叫做根（root）的对象（在 JS 中根是全局对象 `window`），定期让垃圾回收器从根开始，找到所有从根开始引用的对象，再找到这些对象的引用对象。垃圾回收器会找到所有可以获得的对象和所有不能获得的对象，回收不能获得的对象。

### [重点] 深拷贝与浅拷贝的区别

- 深拷贝层层拷贝，浅拷贝只拷贝第一层，深层只是引用。
- 深拷贝中，新对象中的更改不会影响原始对象；浅拷贝中，新对象中的更改会影响原始对象。
- 深拷贝中，原始对象不与新对象共享相同的属性；浅拷贝中，它们具有相同的属性。
- 浅拷贝是值的赋值，对于对象是内存地址的赋值，目标对象的引用和原对象的引用指向同一块内存空间。其中一个对象改变，就会影响另一个对象。
- 深拷贝是将一个对象从内存中完整拷贝一份，对象与对象间不共享内存，而是在堆内存中新开辟空间存储，所以修改新对象不会影响原对象。

浅拷贝示例：

```js
let arr1 = [{ a: 1, b: 2 }, { c: 1 }]
let newArr = arr1.slice()

let newArr2 = [...arr1]

Object.assign({}, sourceTarget)
```

### JSON.parse(JSON.stringify()) 深拷贝的问题

1. 如果 `obj` 里面有时间对象，`JSON.stringify` 后再 `JSON.parse`，时间会变成字符串形式，而不是对象形式。
2. 如果 `obj` 里有 `RegExp`、`Error` 对象，序列化结果只得到空对象。
3. 如果 `obj` 里有函数、`undefined`，序列化结果会丢失函数或 `undefined`。
4. 如果对象里有 `NaN`、`Infinity`、`-Infinity`，序列化结果会变成 `null`。
5. `JSON.stringify()` 只能序列化对象的可枚举自有属性。如果 `obj` 中的对象由构造函数生成，深拷贝后会丢弃对象的 `constructor`。
6. 如果对象存在循环引用，无法正确实现深拷贝。

### 手写深拷贝

```js
function deepClone(obj, map = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj

  const type = Object.prototype.toString.call(obj).slice(8, -1)
  let strategy = {
    Date: (obj) => new Date(obj),
    RegExp: (obj) => new RegExp(obj),
    Array: clone,
    Object: clone
  }

  function clone(obj) {
    if (map.get(obj)) return map.get(obj)
    let target = new obj.constructor()
    map.set(obj, target)
    for (let key in obj) {
      if (obj.hasOwnProperty(key)) {
        target[key] = deepClone(obj[key], map)
      }
    }
    return target
  }

  return strategy[type] && strategy[type](obj)
}
```

### 怎么在不使用变量的情况下交换两个变量的值

```js
let a = 1
let b = 2
;[b, a] = [a, b]
```

原理：

1. 以从左到右的顺序计算右侧数组的值，得到数组。
2. 以从左到右的顺序，将右侧数组的值赋值给左侧。

解构赋值过程中会有一个包含两个元素的临时数组，并没有比传统方法节省空间，甚至空间会比传统方法多一个 int 值大小的空间。

### 斐波拉契数列数组

```js
const map = new Map()
const list = []

function fn(num) {
  if (map.has(num)) {
    return map.get(num)
  }

  if (num === 1 || num === 2) {
    if (!map.has(num)) {
      list.push(1)
      map.set(num, 1)
    }
    return 1
  }

  const result = fn(num - 1) + fn(num - 2)
  map.set(num, result)
  list.push(result)
  return result
}

console.log('list', list)
```
