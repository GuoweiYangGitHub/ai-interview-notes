## 构建工具

完整内容见 [构建工具](/01-前端基础/06-工程化与性能/构建工具)。

### [重点] Webpack 的构建流程

初始化阶段（合并配置、创建 Compiler、初始化插件、run）→ 编译阶段（Compilation、make、生成 modules、`buildModule` 执行 loader、`Parser.parse` 生成 AST 收集依赖、`seal` 生成 chunks）→ 生成文件阶段（`createChunkAssets`、`emit`、`done`）。

### loader 是什么？执行顺序如何？

- loader 是文件加载器，加载资源文件并处理（编译、压缩等），最终打包到指定文件。
- 多个 loader 的执行顺序与配置顺序相反：最后一个最先执行，第一个最后执行。
- 第一个 loader 接收源文件内容，其他 loader 接收前一个 loader 的返回值，最后一个 loader 返回模块的 JavaScript 源码。

### less 是怎么编译成 CSS 的

`less-loader` 把 less 编译成 CSS → `css-loader` 解析 CSS → `style-loader` 挂载到 HTML。完整链路见 [构建工具](/01-前端基础/06-工程化与性能/构建工具)。

### `require.context` 的三个参数

读取文件的路径、是否遍历子目录、匹配文件的正则。常用于批量注册组件。

### Webpack 的优化手段

gzip 压缩、splitChunks 切割、JS 最小化、图片压缩。配置见 [构建工具](/01-前端基础/06-工程化与性能/构建工具)。

## 性能优化

完整内容见 [性能优化](/01-前端基础/06-工程化与性能/性能优化)。

### [重点] 首页首次加载白屏怎么处理

- SSR：服务端渲染，利于 SEO、加快内容展示。
- 预渲染：构建时用 puppeteer / jsdom 渲染静态部分，不渲染异步数据。
- 骨架屏：在真实页面展示前，用灰色矩形或圆形块展示页面的大概布局。

### [重点] 提升页面性能的方法

从资源、网络、渲染三个层面答：压缩合并与减少 HTTP 请求、非核心代码异步加载、浏览器缓存与 CDN、DNS 预解析、减少重绘回流、防抖节流、避免频繁操作 DOM 和 style、CSS 优化。完整清单见 [性能优化](/01-前端基础/06-工程化与性能/性能优化)。

### Vue 相关性能优化

- 使用单文件组件预编译模板。
- 提取组件 CSS 到单独文件。
- 减少 localStorage 持久化写入频率，合并写入。
- 为持久化缓存设计旧数据清除策略。
- 组件懒加载，配合骨架屏。

## 自动化测试

完整内容见 [自动化测试](/01-前端基础/06-工程化与性能/自动化测试)。

### [重点] 自动化测试的价值与流程

流程是输入 → 断言 → 验证。价值是减少耗时时间和人力成本，不漏测功能，不需要手动输入数据和点击页面。人工测试靠人机交互，自动化测试靠脚本与程序交互。

### 单元测试和集成测试 / E2E 的区别

- 单元测试：测试程序最小单元，速度快、覆盖率高、易于维护，但无法验证多个单元组合后的正确性。
- 集成测试 / E2E：把不同模块集成在一起，站在用户视角、以真实运行环境测试完整流程，边界较模糊，常放在一起介绍。

### [重点] TDD 和 BDD 的区别

- TDD：先写测试后实现功能；流程是写用例、运行、编码通过、重构、重复；覆盖率高，但测试代码量大、需求可能偏离。
- BDD：先实现功能后写测试（面向行为）；关注需求完整度，多结合集成测试，测试代码与实际代码解耦，但覆盖率较低。
