# Python 与 JavaScript 对照

面向 JS 背景，把两边常用写法按**从易到难**叠起来。不按课时。

建议顺序：

1. [值与判断](/语法对照/01-值与判断) — `True` / `None` / `and`
2. [导入与函数](/语法对照/02-导入与函数) — `import`、`def`、`*args` / `**kwargs`
3. [对象与列表](/语法对照/03-对象与列表) — dict、list、`.get`、`{**base}`
4. [字符串与格式化](/语法对照/04-字符串与格式化) — `split` / `join` / f-string
5. [循环与推导](/语法对照/05-循环与推导) — `for`、`enumerate`、`next`、`while`
6. [切片与排序](/语法对照/06-切片与排序) — `[:]`、`sorted`、拍平
7. [异常与文件](/语法对照/07-异常与文件) — `try`、`Path`、`rglob`、`subprocess`
8. [类型与模型](/语法对照/08-类型与模型) — typing、dataclass、Pydantic
9. [异步](/语法对照/09-异步) — `asyncio.run`、`gather`、`yield`
10. [进阶](/语法对照/10-进阶) — 闭包、装饰器、CLI、TypedDict
